# 토모리(Tomori) — 전체 플로우 & 디자인 브리프

> 일본어 학습 앱. 캐릭터 **토모(작은 등불)**, 리워드 **우표 → 편지**.
> **핵심 철학: "학습 의지를 꺾지 않고 북돋아 준다. 수익 요소가 학습을 방해하지 않는다."**
> 규모: 화면 52 · Hi-fi 프레임 77 · 5개 코스 · JLPT 4영역 · 기준 PRD v2.7 / 사양서 v3.2

이 문서 하나로 **① 화면이 어떻게 이어지는가(플로우)** + **② 각 화면이 무엇인가(인덱스)** + **③ 어떤 색·규칙으로 입히는가(디자인 토대)** 를 전달합니다.

---

## 1. 주요 흐름 (텍스트)

```
온보딩:   스플래시(1) → 앱 소개(2) → 회원가입(3) → 진단 4문항(4)
          → 추천 결과(5) → 레벨 테스트(6) → 첫 학습(7) → 홈(8)

홈 허브:  홈(8) ⇄ [ 코스 목록(10) · 단어장(22) · 번역(28) · MY(34) ]   ← 하단 탭바
          홈(8) → 코스 퀵메뉴(9)

학습 루프: 코스 목록(10) → 코스 상세·커리큘럼(11) → 레슨(12/13/14)
          → 퀴즈 6유형(16) → 정답·오답(17)
              ├─ 오답 → 오답노트 자동저장(18)
              └─ 우표 적립(19) → 학습 요약(20/21) → 홈(8)

오답 복습: 오답노트(18) → 오답노트 모아보기(47) → [다시 풀기] → 퀴즈(16)
          오답노트 모아보기(47) → 오답노트 PDF(45)

단어 저장: 레슨·단어 팝업(15) → [저장] → 단어장(22)

카메라:   번역 랜딩(28) → 촬영(29) → OCR 처리(30)
          → 인식 결과(31 매칭됨 / 32 매칭없음) → 단어 팝업(15)
          → 저장 위치 선택(33) → 단어장(22)

구독:     D6 배너(40) → 플랜 선택(41) → 결제(42) → 완료(43)
                                      └→ 무료 유지(44)
          MY 구독 관리(36) → 플랜 선택(41)

곁가지:   홈(8) → 토모의 쪽지(50)
          홈(8) → 시험일 설정(46) → JLPT 레슨(14)
          홈(8) → 오프라인 진입(51) → 콘텐츠 미리받기(52) →(비구독) 플랜 선택(41)
```

**핵심 구조 메모**
- **홈(8)이 허브** — 하단 탭바로 학습·단어장·번역·MY 어디서든 홈으로 돌아옴.
- **혼합형 레슨(14, JLPT)의 4영역(단어·문법·독해·청해)은 자유 전환 탭이 아님.** 영역 선택은 코스 상세(11)의 세로 리스트에서 하고, 학습 화면 상단은 "현재 영역" 위치 라벨만 표시.
- **강제 진행 없음** — "다시 보기"를 어느 결과 화면에서도 지우지 않음.

### 타이포 · 형태
- **한글 UI** — Pretendard
- **일본어 학습 콘텐츠**(예문·후리가나) — Noto Sans JP
- **브랜드 · 토모** — Zen Maru Gothic (둥근 서체, 한글 글리프 없음)
- **모서리 반경** — 9 / 15 / full (3단 고정)
- **후리가나** — 루비 공간을 항상 확보하고 표시만 토글 → 켜고 꺼도 본문이 점프하지 않음

### 핵심 규칙 (꼭 지킬 것 — 안 지키면 "투박함"이 생김)
1. **앰버는 우표·빛 전용.** 앰버가 보이면 "우표 얘기"라는 신호. 버튼·일반 강조에 쓰지 않는다.
2. **코스색은 액센트만.** 4px 바·글자·진행바에만. **면 전체를 코스색으로 채우지 않는다.** (다크에서 코스색 면+흰 글자는 대비 미달)
3. **상태색(성공/오류)은 학습 판정에만.** 시스템 오류·로딩엔 중립색.
4. **토모는 학습 중 말 걸지 않는다.** 판단·집중 화면엔 등장하지 않고, 결과·쉼에만 "평소 밝기 + 말 없음"으로 비춘다. ("새 쪽지" 신호일 때만 살짝 밝아짐)
5. **강제 진행 없음.** "다시 보기"를 결과 화면에서 지우지 않는다.
6. **라이트·다크 둘 다** 설계. 다크에서 앰버는 유지, 코스색은 밝은 톤으로, Primary는 `#DAD2C7`로 세기를 낮춘다.

## 4. 디자인 입히는 순서 (권장)
1. **여정 한 흐름씩** 디자인한다 (예: 온보딩 ① 또는 학습 루프 ③→④→⑤). 한 번에 전체보다 흐름 단위가 일관성에 유리.
2. 위 **팔레트·타이포·규칙을 고정값**으로 준다. 특히 `앰버=우표 전용`, `코스색=액센트만`은 필수.
3. 화면별 상세 모양은 **Hi-fi 목업(77프레임)**을 참조. 이 문서는 "어디로 이어지는가", 목업은 "각 화면이 어떻게 생겼는가".
4. **라이트·다크 둘 다** 그린다.
