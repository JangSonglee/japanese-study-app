# FE 본편 — JLPT 단어 수직선 설계 (첫 조각)

> 작성 2026-07-28 · 담당 무스부(FE) · 브레인스토밍 승인 후 스펙화
> 상위 맥락: `기획/진행상태.md` · 화면 목록 `기획/claude_code_handoff.md` · PRD 8.4 / 1.3 / 14.2.1

## 1. 목표

공개된 JLPT 단어 **2,009건**을 실제 앱 흐름으로 만질 수 있게 하는 **첫 수직선**을 세운다.
지금은 카드 1화면(슬라이스)뿐이라 "데이터는 있는데 앱 껍데기가 없는" 상태 — 홈부터 세션까지 **끝까지 걸어지는 하나의 길**을 만든다.

**범위 결정(대표님 승인 2026-07-28):**
- 첫 조각 = **JLPT 단어 수직선만** (온보딩·다른 탭·다른 코스는 각각 별도 조각).
- 홈 = **토모 + 「학습 시작」 CTA만** (스트릭·진도 위젯은 데이터 없어 생략).
- 네비게이션 = **손수 만든 가벼운 스택** (react-navigation 아님 — RN Web+Vite 번들 불안정).
- **하단 5탭 바 없음** (단어장·번역은 콘텐츠가 없어 빈 탭이 되면 "미완성 미노출" 철학 위반).

## 2. 왜 이 범위인가 (이유)

- BE에 실제로 있는 건 **단어뿐**. 문법·독해·청해 콘텐츠, 단어장 저장 데이터, 카메라 OCR은 없다. 5탭을 다 세우면 대부분 빈 화면 → 철학(진행상태.md 「곧 열려요는 코스 단위에만」) 위반.
- **로그인(Auth)이 없어** `user_id`가 없다. 스트릭·우표·"만난 단어 누적"은 서버 원장 쓰기라 로그인 전엔 불가 → 홈에서 정직하게 **생략**한다(가짜 위젯을 두지 않는다).
- 세션 요약(20)은 이미 `WordCardScreen`의 `DoneView`로 구현돼 있다 → **새로 만들지 않고** 카드의 `‹ 뒤로`만 배선.

## 3. 네비게이션 설계 — 손수 만든 스택

`src/nav/router.js` — 라우트 스택 상태 훅.

- 상태: `stack: Array<{ name, params }>` (초기 `[{name:'home'}]`). 현재 화면 = 스택의 top.
- API: `push(name, params)` · `pop()` · `replace(name, params)` · `reset(name)` · `current`.
- 뒤로: 각 화면의 `‹`가 `pop()`. 스택이 1개면 `‹` 미표시(홈은 루트).
- `App.jsx`가 `current.name`으로 화면 컴포넌트를 스위칭하고, 각 화면에 `nav`와 `params`를 내려준다.
- **기존 `screen` 토글( 'card' | 'settings' )을 이 스택으로 대체.** 급수 선택 dev 칩(폰 밖)은 제거 — 급수 선택은 JLPT 허브(11)로 이동.

> Expo 정식 이식 때 react-navigation(native-stack)으로 교체한다. `vite.config.js` 배선과 같은 성격의 예고된 교체 지점이다. 라우트 이름·params 형태를 react-navigation과 호환되게(문자열 name + params 객체) 유지해 이식 비용을 줄인다.

라우트 표:

| name | 화면 | params |
|---|---|---|
| `home` | 홈 (8) | — |
| `courses` | 코스 목록 (10) | — |
| `jlptHub` | JLPT 허브 (11) | — |
| `wordSession` | 단어 세션→요약 (14+20) | `{ level }` (예 `'N5'`) |
| `my` | MY 홈 (34) | — |
| `settings` | 설정 (35) | — |

## 4. 화면별 명세

### 4.1 홈 (`HomeScreen.jsx`, 신규 · 8)
- **토모 등불**(임시 스탠드인, `DoneView`의 토모를 `Tomo.jsx`로 추출해 공유) — 평소 밝기, 말풍선 없음(밝아짐은 「새 쪽지」 전용, PRD 14.2.1).
- 인사말(토모 톤, 한국어) + **「오늘의 학습 시작」 Primary CTA** → `push('courses')`.
- 우상단 프로필 아이콘/버튼 → `push('my')`.
- 스트릭·오늘의 학습·진도 위젯 **없음**(데이터 없음 — 생기면 추가).
- 상단 라이트/다크 토글은 유지(개발 확인용, App 레벨).

### 4.2 코스 목록 (`CourseListScreen.jsx`, 신규 · 10)
- 5개 코스 카드: **JLPT · 여행회화 · 비즈니스 · 뉴스/시사 · 전래동화**.
- **JLPT만 활성** → `push('jlptHub')`. 나머지 4개는 **「곧 열려요」** 비활성(코스 단위엔 허용 — 진행상태.md 결정. 코스 *아래* 단위만 미노출).
- `‹ 뒤로` → `pop()`(홈).

### 4.3 JLPT 허브 (`JlptHubScreen.jsx`, 신규 · 11)
- **급수 선택**: N5·N4·N3·N2·N1 칩(기존 App의 급수 칩 로직을 여기로 이관). 기본 N5.
- **영역 세로 리스트**: 지금은 **「단어·어휘」 한 줄만** 노출(문법/독해/청해는 콘텐츠 없어 **아예 안 보임** — "코스 아래 단위 미노출"). 각 영역 행 = 이름 + 진행률 자리 + `>`.
- 단어 행 탭 → `push('wordSession', { level })`.
- 진행률(수집형 누적)은 서버 원장 연결 후. 지금은 자리만/비움(정직 표기).
- 상단 = 현재 위치 라벨(코스 액센트 바 + course-text) — JLPT_플로우 섹션 C(세로 리스트가 영역 전환 UI). `‹ 뒤로` → 코스 목록.

### 4.4 단어 세션 → 요약 (`WordCardScreen.jsx`, **수정** · 14+20)
- **재사용.** 변경점:
  - `‹ 뒤로`(현재 텍스트만) → `onPress={() => nav.pop()}` 배선(→ JLPT 허브).
  - `params.level`로 급수 표시(appbar/영역 라벨), 카드 로드는 App이 `loadCards(level,10)`로 이미 주입.
- `DoneView`(요약)는 그대로. CTA 「테스트 시작하기」는 슬라이스에 테스트 없어 재시작 유지(기존 동작).

### 4.5 MY 홈 (`MyScreen.jsx`, 신규 · 34)
- 프로필 요약: 로그인 없으니 **"게스트"** + 간단 안내(로그인은 이후 조각).
- 메뉴 리스트: **설정**(→ `push('settings')`). 학습통계·구독·알림·계정은 데이터/기능 없어 이 슬라이스에 미노출(또는 「곧 열려요」 — 구현 시 판단, 기본은 미노출).
- `‹ 뒤로` → 홈.

### 4.6 설정 (`SettingsScreen.jsx`, **재사용** · 35)
- 기존 그대로(읽기도움 기본값 2토글 + Tanos 크레딧). `onBack`을 `nav.pop()`에 연결.

## 5. 데이터 / 상태 — 무엇이 진짜인가

| 구분 | 항목 |
|---|---|
| **진짜(실동작)** | 급수별 단어(실 Supabase, `loadCards`) · 세션 자가판정 집계(클라이언트 known/total) · 읽기도움 설정(localStorage `tomori.readAid`) · 카드 ★저장(세션 내 로컬 Set) |
| **보류(정직하게 비움)** | 스트릭 · 우표 적립 · "만난 단어 누적 진행률"(서버 원장=로그인 필요) · 단어장 영구저장 · 문법/독해/청해 · 다른 4개 코스 |

- 급수 선택은 **JLPT 허브**에서 → `push('wordSession', { level })`로 전달. **카드 로드는 `wordSession` 진입 시** 해당 `level`로 `loadCards(level, 10)` 실행(로딩/에러 상태 포함). 카드 세트는 `key={level}`로 리셋. (현재 App이 `level` 변경마다 로드하던 것을 라우트 진입 기준으로 옮김.)
- 읽기도움 `settings`는 App 보유(localStorage) → 세션·설정 화면에 주입(현행 유지).

## 6. 파일 구조

```
신규
  src/nav/router.js               스택 상태 훅(push/pop/replace/reset/current)
  src/components/Tomo.jsx          토모 등불 스탠드인(DoneView에서 추출, 홈·요약 공유)
  src/screens/HomeScreen.jsx       (8)
  src/screens/CourseListScreen.jsx (10)
  src/screens/JlptHubScreen.jsx    (11)
  src/screens/MyScreen.jsx         (34)
수정
  src/App.jsx                      screen 토글 → 라우터 스위칭. 급수 dev칩 제거(급수는 허브로)
  src/screens/WordCardScreen.jsx   ‹ 뒤로 onPress 배선 + level 표시. 내부 DoneView의 토모를 Tomo.jsx로 교체(선택 — 중복 제거)
```

- 각 화면은 **한 가지 목적**, `nav`·`params`·`settings`만 의존(잘 정의된 인터페이스). 내부를 바꿔도 다른 화면이 안 깨진다.
- 코스색·토큰은 반드시 `tokens.js`만 참조(사양서 1.2). 원시 hex 직접 사용 금지.

## 7. 검증 (수용 기준)

빌드 + preview(5599)에서 브라우저로 확인(🔴 `vite dev` 금지 — 진행상태.md 재기동 절차):
1. 홈 → 「학습 시작」 → 코스 목록 → JLPT → 허브에서 N5 선택 → 단어 → 카드 렌더(실 Supabase) → 10장 완주 → 요약(아는/모르는) → `‹`로 허브 복귀.
2. 허브에서 급수 N5↔N2 바꾸면 카드 세트 교체(실 데이터).
3. 홈 → 프로필 → MY → 설정 → 읽기도움 토글·Tanos 링크 → `‹` 복귀.
4. 코스 목록의 비-JLPT 4개는 「곧 열려요」로 비활성, 허브에 문법/독해/청해 **안 보임**.
5. 라이트/다크 모두 정상 · 콘솔 에러 0 · 뒤로 스택 정상(홈에서 `‹` 없음).
