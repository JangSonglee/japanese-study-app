## 진행 순서 (의존성)
- **도다이(BE)**: 지금부터 병행 착수 가능 — 데이터 모델·스키마는 화면과 무관하게 선행 가능
- **무스부(FE)**: 디자인 시스템 확정 후 본격 착수. 단, 공통 로직(네비게이션 구조·상태관리 뼈대)은 지금부터 병행 가능
