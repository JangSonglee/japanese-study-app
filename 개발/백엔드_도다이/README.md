## 업무 범위
- 회원가입·로그인(소셜), 학습 진도·단어장 DB 스키마(PostgreSQL) 설계
- 코스·레슨 콘텐츠 API, **우표** 적립/차감 로직 (원장 방식)
- PDF 생성·할당량 로직 (PRD 12.1 표 기준)
- 구독 결제 연동, 코스 태그·커스텀 태그 데이터 구조 (PRD 6장)

> ⚠️ 용어 정정(2026-07-22): **쿠키 → 우표**로 개편됨 (PRD 12.2). 옛 문서에 "쿠키"가 보이면 우표로 읽을 것.
> Auth 벤더는 **Supabase 통일을 제안 중**(`스키마_설계.md` 6장 ①) — 확정 전까지 Firebase로 단정하지 않는다.
