# 비즈니스 코스 — BJT 축 도입 검토

> 검토: 키카쿠(PM) / 2026-07-22
> 발단: 대표님 제안 — *"BJT · 비즈니스 롤플레잉(모의면접) · 메일/문서 작성 테스트를 바탕으로 기획해볼까?"*
> 상태: **검토안 — 대표님 결정 대기**

## 0. 결론 먼저

**BJT를 도입하되, "코스의 정체성"이 아니라 "난이도 축과 문항 유형의 근거"로만 쓰는 것**을 권합니다.

이유는 아래 3장의 충돌 때문이고, 그렇게 하면 **기존 결정을 뒤집지 않으면서** 우리가 겪던 감수 병목을 상당히 덜어낼 수 있습니다.

## 1. BJT 실제 구조 (확인함)

`kanken.or.jp` 공식 자료 기준.

| 항목 | 내용 |
|---|---|
| 주관 | 日本漢字能力検定協会 |
| 구성 | **제1부 聴解 / 제2부 聴読解 / 제3부 読解** |
| 채점 | **0~800점 스코어제** — 합격·불합격이 아님 |
| 레벨 | **J5 → J4 → J3 → J2 → J1 → J1+** 6단계 (J1+ = 600점 이상, J1 = 530~599) |
| 특징 | 언어 능력만이 아니라 **업무 상황의 정보 처리 능력**을 함께 측정 |

**제2부 聴読解의 3섹션** (우리에게 가장 중요)
1. **状況把握** — 음성 + 사진 → 직장 대화의 핵심 주제 파악
2. **資料聴読解** — 음성 + 그래프·표·광고 → 시각 자료와 음성 정보를 결합
3. **総合聴読解** — 음성 + **견적서·결산표·이메일 화면·프로그램표** 등 실제 업무 문서 → 복합 정보 통합

### 🔴 여기서 꼭 짚어야 할 것

**BJT에는 말하기·쓰기 시험이 없습니다.** 전부 듣기와 읽기입니다.

대표님이 함께 말씀하신 **모의면접(롤플레잉)** 과 **메일 작성 테스트**는 **BJT의 일부가 아니라 별개**입니다.
→ "BJT 기반"이라는 한 덩어리로 묶으면 나중에 "BJT엔 그런 거 없는데?"가 나옵니다. **처음부터 분리해서 다뤄야 합니다.**

## 2. BJT를 도입하면 좋은 점

### ① 🔴 감수 병목의 성격이 바뀐다 — 이게 가장 큽니다

지금 비즈니스 코스가 막혀 있는 이유:
> 리서치에서 **전 영역 `⚠️검증필요`**. 현지 실사용·세대/업계 적합성 미검증 → **일본인 감수 전 확정·출시 금지**

BJT 유형을 축으로 삼으면 판정 질문이 바뀝니다.

| | 지금 | BJT 축 도입 후 |
|---|---|---|
| 판정 질문 | *"우리가 고른 이 표현, 현지에서 진짜 쓰나?"* | *"이 문항이 공식 시험 유형에 맞나?"* |
| 판정 주체 | **현직 일본인만 가능** | 유형 정합성은 **우리도 판정 가능** |
| 감수 범위 | 전 표현 | **표현의 자연스러움만** |

⚠️ **단, 감수가 필요 없어지지는 않습니다.** 경어를 잘못 쓰면 그냥 오류가 아니라 실례이고, 그건 유형을 바꿔도 안 사라집니다.
**감수가 없어지는 게 아니라 빨라집니다** — 감수자가 "표현 자연스러움"만 보면 되니까요.

### ② 난이도 축에 근거가 생긴다

현재 우리 난이도는 **입문/초급/중급/고급** — 우리가 임의로 나눈 것입니다.
BJT **J5~J1+** 를 병기하면 근거가 생기고, 학습자도 자기 위치를 압니다.

### ③ 비즈니스 코스의 "목표 없음" 문제가 풀린다

JLPT는 시험일이 있어 D-day가 붙지만, 비즈니스는 **목표가 모호**합니다. *"일본어 잘하고 싶다"* 는 측정이 안 돼요.
BJT 점수는 명확한 목표가 되고, **46번 D-day 모달을 그대로 재사용**할 수 있습니다(JLPT 시험일 ↔ 여행 출발일 ↔ **BJT 응시일**).

### ④ 우리 스키마가 이미 지원한다 — 구조 변경 불필요

| 스키마 | BJT 대응 |
|---|---|
| `course_levels` | 입문~고급 → **J5~J1+** (컬럼 그대로) |
| `course_tracks` | 경어/이메일·보고서/전화/회의·접대 (그대로) |
| `questions.question_type` | 聴読解 = **기존 `listening` + 자료 이미지** |
| 48 문서 템플릿형 화면 | **総合聴読解의 견적서·메일 화면과 직결** |

→ **새로 만들 테이블이 없습니다.**

## 3. 🔴 충돌하는 것 — 반드시 결정해야 할 지점

### 충돌 ① 기존 결정을 뒤집게 된다

`코스별_플로우_검토.md` 1번에서 이렇게 정했습니다:

> JLPT의 "문법적 정오" 해설 → **"상황 적절성·정중도" 중심으로 전환**
> **3단 해설(오답 선택지별 이유)은 축소** — **시험이 아니므로** 과잉이고 제작비만 증가

BJT를 코스의 정체성으로 삼으면 비즈니스가 **시험 대비 코스**가 되고, 위 결정이 통째로 뒤집힙니다.

> **PM 의견**: 뒤집지 마세요. **해설 축은 "상황 적절성" 그대로 두고**, BJT는 난이도 라벨과 문항 유형에만 씁니다.
> 이유: 우리 사용자 다수는 **BJT 응시자가 아니라 "회사에서 쓸 일본어가 필요한 사람"** 입니다. 설문 30%가 "비즈니스 관심"이라 답한 게 "BJT 보고 싶다"는 뜻은 아닙니다.

### 충돌 ② 콘텐츠 제작비가 오른다

聴読解는 음성만으로 안 되고 **자료 이미지(그래프·견적서·결산표·메일 화면)를 함께 만들어야** 합니다.
→ JLPT 청해보다 **비쌉니다.** 청해 음성 방식(실행계획 갈림길 ②)도 아직 미정인데 부담이 하나 더 얹힙니다.

### 충돌 ③ 모의면접은 "테스트"가 될 수 없다

이미 확정된 사항이 걸립니다 (Lo-fi 3차 수정):
> 스피킹형 퀴즈 — **유사도 판정 폐기** → **자가판정 + 낱말카드 대체 모드**

즉 우리는 **말하기를 채점하지 않기로** 이미 정했습니다. 모의면접은 자유 응답이라 더더욱 판정이 불가능합니다.

> **PM 의견**: 모의면접은 **"테스트"가 아니라 "연습"** 으로 포지셔닝하세요.
> 49번 대화 시뮬레이션형을 확장해 **면접 시나리오**를 넣되, 점수를 매기지 않고 **모범 답변 대조 + 자가판정**으로 갑니다. 이게 우리 철학("꺾지 않는다")과도 맞습니다.

### 충돌 ④ 메일 작성 = 자유 작문 채점 불가

MVP에서 자유 작문을 채점할 방법이 없습니다.

> **PM 의견**: 자유 작문 대신 **이미 있는 퀴즈 유형으로 대체**하면 됩니다 — 새 기능이 필요 없습니다.
> · 빈칸 채우기(받아쓰기형) · 문형 선택(객관식) · **순서 배열형**(메일 구성 순서: 인사→용건→맺음)
> 48번 문서 템플릿형 화면이 이미 이걸 담을 그릇입니다.

## 4. 권장안 — "BJT 정합, BJT 대비 아님"

| 요소 | 채택 | 방식 |
|---|---|---|
| **난이도 라벨** | ✅ | 입문~고급 → **J5~J1+ 병기** (예: `중급 · J3 상당`) |
| **문항 유형 근거** | ✅ | 公式 샘플의 **유형만** 참고해 자체 제작 (JLPT와 동일한 방법) |
| **資料 기반 문항** | ✅ | 견적서·메일 화면 보고 답하기 → **48번 화면과 통합** |
| **응시일 D-day** | ✅ | 46번 모달 재사용 |
| 해설 축 | ❌ 변경 안 함 | **상황 적절성·정중도 유지** (기존 결정 존중) |
| 코스 정체성 | ❌ | "BJT 대비 코스"로 바꾸지 않음. **"실무 일본어 + BJT 정합"** |
| 모의면접 | 🔶 조건부 | 49번 확장, **채점 없음 · 자가판정**. Should |
| 메일 작성 | ✅ | 자유 작문 아님 — **기존 퀴즈 3유형으로 구성**. 48번에 통합 |

### 이 안의 핵심

> **BJT를 "목표"가 아니라 "자"로 쓴다.**
> 사용자는 여전히 실무 일본어를 배우지만, 자기 수준이 J3인지 J2인지 알 수 있고, 원하면 그대로 시험을 볼 수 있다.
> **BJT를 안 볼 사람에게는 아무 부담도 지우지 않는다** — D-day를 "선택적 동기 장치"로 못 박은 것과 같은 논리(코스별 검토 7번).

## 5. 🔴 저작권 — 반드시 지킬 선

| 대상 | 가능 여부 |
|---|---|
| BJT **시험 구조·파트 구성·레벨 체계** | ✅ 사실 정보. 참고 가능 |
| BJT **공식 샘플 문항의 "유형"** | ✅ 유형은 아이디어라 보호 대상 아님 |
| BJT **문항·지문·선택지 자체** | ❌ **복제 금지** |
| 시중 교재의 **단어 목록·예문·해설** | ❌ 단어 하나는 저작물이 아니지만, **"어떤 단어를 골라 어떻게 배열했는가"는 편집저작물** |

> JLPT에서 이미 쓴 방법과 **완전히 동일**합니다 — *"공식 샘플 유형 기반 자체 제작"*(슈슈 리서치 결정).

## 6. 이 검토가 실행계획에 미치는 영향

`실행계획.md` **갈림길 ①(비즈니스를 MVP에 넣을 것인가)** 의 판단이 조금 쉬워집니다.

- 감수 범위가 "전 표현" → "표현 자연스러움"으로 **줄어들기 때문에**, 감수자를 구했을 때 걸리는 시간이 짧아집니다.
- 다만 **콘텐츠 제작비는 오히려 늘어납니다**(資料 이미지). 총 소요가 줄어든다고 단정할 수 없습니다.

→ 갈림길 ①의 **조건부 결정 권고는 유지**합니다.
