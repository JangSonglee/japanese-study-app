# 브랜드 컨셉 재구상 — 6안 (서비스명·리워드 포함 전면 재검토)

> 작성: 키카쿠(PM) / 2026-07-20 / 상태: 제안 (택1 또는 조합)
> 전제: **서비스명·리워드 재화는 변경 가능**. 단 아래 3가지는 불변.
> ① 일본어 학습 앱 ② **학습 의지를 꺾지 않고 북돋움** ③ **수익 요소가 학습을 방해하지 않음**

---

## 0. 진단 — 현행 브랜딩의 근본 문제 2가지

### 문제 1. 🍪 쿠키는 일본어와 아무 상관이 없다
- 5개 코스(JLPT·여행·비즈니스·뉴스·전래동화) 전부 **일본**인데, 보상만 서양 과자다.
- 브랜드 세계관에 일본적 정서가 하나도 없어, 캐릭터가 "일본어 앱의 마스코트"로 읽히지 않는다.

### 문제 2. 🔗 **쿠키 7개 → PDF 1장**의 논리가 없다
- 왜 쿠키를 모으면 PDF가 나오는가? **설명이 불가능한 임의 교환**이다.
- 좋은 재화 설계는 **리워드와 사용처가 은유로 연결**된다. (예: 우표를 모으면 편지가 온다)
- 지금은 이 연결이 없어서 쿠키가 "그냥 포인트"로 느껴진다.

### 문제 3. 이름 "쿠니토"는 쿠니가 정의되지 않으면 빈 껍데기
- 쿠니토 = 쿠니 + と(함께). 그런데 **쿠니가 무엇인지 없으면** 이름도 의미를 못 전달한다.

## 평가 기준
| 기준 | 설명 |
|---|---|
| **철학 적합** | 재촉하지 않음 / 방해하지 않음 / 끝이 없음 |
| **일본 연결** | 일본 문화·언어와의 필연성 |
| **리워드 논리** | 리워드 → 사용처(PDF) 은유가 자연스러운가 |
| **자산 계승** | 현재 플랫 블롭 비주얼을 살릴 수 있는가 |
| **독창성** | 경쟁 앱과 구별되는가 |

# 1안. モチ (모치) — "말이 몸에 붙는다"

| 항목 | 내용 |
|---|---|
| **서비스명** | **모치모치 / Mochi** (もちもち = 쫄깃한 식감 의성어) |
| **캐릭터** | 떡(餅) 한 덩이. 말랑하고 **이미 완성된 상태** |
| **리워드** | **きなこ(콩고물)** — 학습할 때마다 한 스푼씩 쌓임 |

**언어유희**: もち(餅, 떡) ↔ 持ち(가짐) → **"배운 말을 가진다"**
**철학**: 떡은 눌러도 다시 돌아오고, 완성/미완성이 없다. 성장 서사가 원천 차단된다.
**코스 매핑**: 소품만 교체(캐리어·연필·서류가방·신문·책)
**강점**: 현재 **플랫 블롭 비주얼을 그대로 계승** 가능(떡=말랑한 덩어리). 일본 문화 직결. 이름이 귀엽고 한국인 발음도 쉬움.
**약점**: 음식 캐릭터라 **학습과의 논리적 연결은 여전히 약함**(쿠키와 같은 한계). 리워드→PDF 연결도 임의적.

# 2안. あかり (아카리) — 등불 ⭐철학 최적합

| 항목 | 내용 |
|---|---|
| **서비스명** | **아카리 / Akari (灯り, 불빛)** |
| **캐릭터** | 작은 초롱불(提灯). 스스로 빛나되 **길을 대신 걷지 않는다** |
| **리워드** | **ともしび(불씨)** — 모으면 등불이 더 멀리·오래 밝힘 |

**철학**: **"밝혀주되 끌지 않는다"** — 재촉하지 않는 동반자의 완벽한 은유. 14.4 관찰자 톤("말은 아끼되 지켜본다")과 정확히 일치한다.
**정서**: 막히고 어두울 때 곁에 켜져 있는 존재. 며칠 사라졌다 돌아와도 **불은 그대로 켜져 있다** → 이탈 1위 "바빠서"에 대한 정서적 대응.
**코스 매핑**: 코스는 "각기 다른 길", 등불은 어느 길이든 따라간다 → **퀵메뉴 자유 전환 철학과 정합**
**강점**: **철학이 이름 안에 담긴다.** 일본 초롱 문화와 연결. 광고·결제로 방해하지 않는다는 제품 정신이 "빛"이라는 상징에 자연히 얹힘.
**약점**: 잔잔해서 게임적 재미는 약할 수 있음. 불씨→PDF 연결은 보통.

# 3안. ルビ (루비) — 후리가나 요정 ⭐독창성 최고

| 항목 | 내용 |
|---|---|
| **서비스명** | **루비 / Ruby (ルビ)** — 후리가나의 정식 명칭이 **ルビ** |
| **캐릭터** | 한자 **위에 작게 앉아** 읽는 법을 알려주는 존재 |
| **리워드** | **よみ(읽기)** 또는 획(かく) |

**핵심**: 이 앱의 대표 기능인 **읽기 도움 토글(후리가나)이 곧 캐릭터**다. 기능·캐릭터·이름이 하나가 된다.
**철학**: 루비는 **본문을 가리지 않고 위에 조용히 얹힌다** = *방해하지 않는 도움*. 이 앱의 UX·수익 철학과 구조가 동일하다.
**강점**: **일본어 학습 앱에서만 가능한 컨셉.** 극도로 독창적이고, 브랜드명이 세련됨. 캐릭터가 화면에 작게 등장하는 것도 자연스러움(흐름 방해 없음).
**약점**: "루비"가 **보석으로 오인**될 수 있음(과금 재화 느낌 주의). 개념이 지적이라 직관적 귀여움은 덜함.

# 4안. えんがわ (엔가와) — 툇마루

| 항목 | 내용 |
|---|---|
| **서비스명** | **엔가와 / Engawa (縁側)** |
| **캐릭터** | 툇마루에 **늘 앉아 있는** 작은 존재 |
| **리워드** | **お茶(차) 한 잔** — 학습 후 함께 마시는 것 |

**철학**: 툇마루는 안도 밖도 아닌 **머무는 자리**다. **"언제 와도 그 자리에 있다"** → 복귀 장벽 제거. 오래 쉬었다 돌아온 사용자에게 가장 강한 정서.
**강점**: **"돌아올 곳"** 이라는 정서가 재방문 동기와 직결. 일본 가옥 문화. 성장 서사가 원천적으로 성립하지 않음(공간은 성장하지 않음).
**약점**: 공간 컨셉이라 **캐릭터 형태를 별도 설계**해야 함. 이름이 한국인에게 생소.

# 5안. もり (모리) — 끝없이 자라는 숲

| 항목 | 내용 |
|---|---|
| **서비스명** | **모리 / Mori (森)** |
| **캐릭터** | 숲에 사는 작은 존재 |
| **리워드** | **たね(씨앗)** — 심으면 나무가 되고, 나무가 모여 숲이 된다 |

**철학 재해석**: 성장하되 **완성이 없다.** 숲은 끝나지 않는다 → *"학습에 끝이 없다"* 를 결핍이 아니라 **풍요**로 표현한다.
**강점**: 시각적 성취(숲이 커짐)가 강력한 재방문 동기. 쿠키보다 훨씬 풍부한 보상 표현. 5개 코스를 "다섯 종류의 나무"로 은유 가능.
**약점**: ⚠️ **PRD 14.1이 기각한 성장 서사와 충돌 소지**(단, 기각 사유는 "완성되면 끝"이었으므로 완성이 없는 숲은 논리상 세이프 — 재논의 필요). Forest 등 기존 앱과 **기시감**.

# 6안. ふみ (후미) — 편지 ⭐리워드 논리 최고

| 항목 | 내용 |
|---|---|
| **서비스명** | **후미 / Fumi (文, 편지·글)** |
| **캐릭터** | 편지를 전하는 작은 존재 |
| **리워드** | **きって(우표)** |

**핵심 강점**: **우표를 모으면 편지가 온다 → PDF를 받는다.**
현재 "쿠키 7개 → PDF"는 왜 그런지 설명이 안 되지만, **우표 → 편지(PDF)** 는 **유일하게 논리가 완결되는 구조**다. 리워드와 사용처가 은유로 이어진다.
**철학**: 편지는 재촉하지 않는다. 천천히 도착하고, 늦게 읽어도 사라지지 않는다.
**언어와의 연결**: 언어는 곧 **전하는 것**. 학습 결과물(오늘 배운 단어·오답노트)이 **나에게 오는 편지**가 된다.
**강점**: **PDF 내보내기라는 제품의 핵심 보상 구조와 브랜드가 완벽히 맞물림.** 학습 기록(8.3)도 "지난 편지들"로 자연히 은유됨.
**약점**: 캐릭터 형태 설계가 새로 필요. 다소 차분해 게임성은 약함.

## 추천
- **단독 1순위: 2안 아카리** — 철학이 이름에 담기고, 어느 축에서도 약점이 없음.
- **독창성 우선: 3안 루비** — 기능=캐릭터=철학. 이 앱에서만 가능한 컨셉.
- **조합 제안 ⭐**: **캐릭터=아카리(등불) + 리워드=우표/편지(6안)**
  → 등불이 밤새 곁을 지키고, 하루 학습이 끝나면 **편지 한 통(PDF)** 이 온다. 철학·논리·정서가 모두 맞물린다.
