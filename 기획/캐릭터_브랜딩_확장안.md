## 0. 진단 — 왜 아직 애매한가

PRD 14장에 **성격(14.4)·스타일(14.3)·운용 규칙(14.2)** 은 있는데, 정작 가장 앞에 와야 할 것이 비어 있다.

### 🔴 핵심 공백: **"쿠니는 무엇인가"가 정의되어 있지 않다**
- 초기 컨셉에서 쿠니는 **"완성된 쿠키"** 였다(반죽 요정 5명이 성장해 도달하는 목표).
- 그런데 14.1에서 **성장 서사 전체를 기각**하면서, 그 서사에 얹혀 있던 **"쿠니=완성된 쿠키"라는 정체성도 함께 사라졌다.**
- 남은 것은 14.3의 "외곽선 없는 플랫 블롭"뿐인데, 이건 **형태**일 뿐 **무엇의** 블롭인지가 없다.
- → 디자이너 입장에선 "말랑한 덩어리를 그려라"는 지시만 있고 **정체가 없어** 그릴 수가 없다. 이게 애매함의 근원.

### 부수 공백
1. **쿠키 보상 시스템과 캐릭터의 관계 단절** — 쿠키는 여전히 핵심 보상(PRD 12.2, 화면 19)인데, 캐릭터와의 연결고리가 기각과 함께 끊겼다.
2. **소품 2종 누락** — 14.2 소품 목록에 5개 코스 중 **뉴스·시사와 전래동화가 없다**(여행=캐리어 / 비즈니스=서류가방 / JLPT=연필만 존재).
3. **표정·포즈·금기 미정의** — 14.4가 성격은 정했으나 그것이 얼굴로 어떻게 번역되는지 없음.
4. **크기별 운용 규칙 없음** — 14.3이 "작은 아이콘으로 축소돼도 인식"을 요구하는데 검증 기준이 없음.

## 1. 정체성 3안 (택1 필요)

세 안 모두 PRD 14.2 제약(**단일 고정 · 성장 없음 · 코스별 분리 없음 · 소품만 변화**)을 지킨다.

### A안. **쿠니 = 다 구워진 쿠키** ⭐ 권장
- 쿠니는 **이미 완성된 쿠키**다. 더 구워질 필요가 없어서 **변하지 않는다.**
- "성장하지 않음"이 결핍이 아니라 **완결**이므로 14.2의 "항상 동일한 모습"과 논리가 딱 맞는다.
- **쿠키 보상과 자연 연결**: 학습으로 모으는 쿠키는 **쿠니가 건네는 것**. 쿠니는 굽는 존재가 아니라 *나눠주는* 존재.
- 브랜드명: **쿠니 + と(~와 함께)** = "쿠니와 함께" (14.4와 동일).
- **장점**: 제품 핵심 보상(쿠키)과 브랜드가 한 몸이 된다. 이름·비주얼·시스템이 삼각으로 맞물림. 초기 컨셉의 자산(쿠키 세계관)을 성장 서사만 버리고 살릴 수 있음.
- **주의**: "완성됐다"가 *학습의 끝*으로 오독되지 않게 해야 함 → **쿠니는 학습자가 아니라 동반자**임을 서사에서 못 박는다. 완성된 건 쿠니지 사용자가 아니다.

### B안. **쿠니 = 일본어라는 땅(くに)의 안내자**
- くに(国, 나라·고향)에서 온 이름. **쿠니토 = 쿠니(땅) + と(함께)** = "이 땅과 함께 간다".
- 5개 코스를 "여러 지역"으로 은유 — 여행회화(거리)·뉴스(오늘의 세상)·전래동화(옛이야기의 숲).
- **장점**: 탐험 세계관이 카메라 번역(PRD 5장)·여행 코스와 잘 붙음. 확장성 좋음.
- **단점**: **쿠키 보상 시스템과 연결이 끊긴다.** 왜 학습 보상이 하필 쿠키인지 설명이 안 됨.

### C안. **쿠니 = 정체를 규정하지 않는 순수 동반자**
- 무엇도 아닌, 그냥 곁에 있는 말랑한 존재.
- **장점**: 제작 자유도 최대, 어떤 코스에도 이질감 없음.
- **단점**: 서사가 없어 **기억에 남지 않는다.** 브랜딩 관점에서 가장 약함. 지금의 "애매함"이 그대로 유지됨.

> **권장: A안.** 유일하게 브랜드명·보상 시스템·비주얼이 하나로 묶이고, 기각된 것(성장 서사)만 정확히 도려낼 수 있다.

## 2. 스토리텔링 (A안 기준 초안)

### 세계관 한 문단
> 쿠니는 이미 다 구워진 쿠키다. 더 부풀 것도, 더 익을 것도 없어서 쿠니는 서두르지 않는다.
> 쿠니가 하는 일은 하나뿐이다 — 배우려는 사람 곁에 앉아, 조용히 지켜보는 것.
> 오래 걸려도 재촉하지 않고, 며칠 사라졌다 돌아와도 이유를 묻지 않는다.
> 다만 다 보고 있다가, 꼭 필요한 순간에 한마디를 건넨다.
> 그리고 하루의 학습이 끝나면 쿠키 하나를 조용히 내민다.

### 왜 쿠니는 재촉하지 않는가 (성격의 근거)
쿠니 자신이 **이미 완성된 존재**라서, 무언가를 빨리 이뤄야 한다는 감각이 없다.
→ 14.4의 "재촉하지 않음 / 판단하지 않음"이 **캐릭터 설정에서 자연히 도출**된다. (성격을 따로 외울 필요가 없어짐)

### 완성 ≠ 학습의 끝 (오독 방지 장치)
완성된 것은 **쿠니**이지 **사용자**가 아니다. 쿠니는 목표가 아니라 **동반자**다.
사용자는 쿠키가 되지 않는다 — 그래서 학습에 끝이 없다는 철학이 유지된다.
(초기 컨셉이 기각된 이유가 "사용자가 완성된 쿠키가 되는 것"이었으므로, 이 구분이 핵심이다)

### 접점별 등장 시나리오 (14.4 말투 연동)
| 접점 | 쿠니의 행동 | 톤 |
|---|---|---|
| 온보딩 | 시작점을 짚어 줌 | 든든하되 짧게 |
| 학습 중 | **등장하지 않음** (흐름 방해 금지) | — |
| 오답 | 지난번에도 걸린 곳임을 기억해 알려줌 | 세심 |
| 재접속 | 새 표현이 쌓였다고 슬쩍 | 옅은 호기심 |
| 오래 복귀 | 이유를 묻지 않음 | 담담 |
| 쿠키 적립 | 쿠키를 조용히 내밈 | 과한 축하 없음 |
| 구독 안내 | 강권하지 않음 | 담백 |

## 3. 디자이너 실무 스펙 (정체성 선택과 무관하게 확정 가능)

### 3.1 형태
- **외곽선 없는 부드러운 플랫 블롭** (14.3 확정)
- **몸통이 곧 얼굴**인 단일 덩어리 권장 — 머리/몸 분리 없음. 팔은 짧게, 다리는 생략하거나 최소.
- 실루엣만으로 식별되어야 함(색·디테일 제거해도 알아볼 것)
- **축소 검증**: 16px·24px 아이콘으로 줄여도 인식되는지 반드시 테스트 (14.3 요구사항)

### 3.2 표정 세트 (감정 진폭 **작게** — 관찰자 성격)
| 표정 | 사용처 |
|---|---|
| 기본 — 잔잔히 지켜봄 | 대부분의 화면 |
| 옅은 반김 | 재접속·복귀 |
| 세심히 살핌 | 오답·복습 (안경 착용) |
| 옅은 호기심 | 새 표현·발견 |
| 담담·단정 | 비즈니스 |
| 조용한 끄덕임 | 성취 인정 (환호 아님) |

**금지 표정**: 폭소 / 깜짝 놀람 / 슬픔·눈물 / 화남 / 윙크 남발 → 전부 14.4의 절제된 관찰자 톤과 충돌.

### 3.3 소품 (14.2 + 누락분 보완 제안)
| 상황 | 소품 | 출처 |
|---|---|---|
| 여행 회화 | 캐리어 | 14.2 확정 |
| 비즈니스 | 서류가방 | 14.2 확정 |
| JLPT | 연필 | 14.2 확정 |
| 오답노트·복습 | 안경 | 14.2 확정 |
| 재접속 인사 | 손 흔들기 | 14.2 확정 |
| **뉴스·시사** | **신문** | ⚠️ **14.2 누락 — 보완 제안** |
| **전래동화** | **책** | ⚠️ **14.2 누락 — 보완 제안** |
- 소품은 **앱이 문맥에 맞춰 자동 노출**. 사용자 커스터마이징 아님(14.2).
- 소품이 바뀌어도 **형태·성격은 절대 불변**.

### 3.4 애니메이션 톤
- **느리고 작게.** 통통 튀거나 빠르게 흔들리지 않음.
- 쿠키 적립(화면 19)에서도 **폭죽·팡파레 금지** → 조용한 반짝임, 쿠키를 내미는 작은 동작.
- 로딩·전환에서 캐릭터가 주의를 뺏지 않을 것.

### 3.5 크기별 운용
| 용도 | 크기 | 디테일 |
|---|---|---|
| 앱 아이콘 | 소형 | 실루엣만, 소품 없음 |
| 온보딩·완료 | 대형 | 표정+소품 전체 |
| 화면 내 보조 | 소형 | 표정 최소, 소품 1개 |
| 오답·복습 | 중형 | 안경 필수 |

### 3.6 절대 금기 (PRD 근거)
1. **성장·변형 표현 금지** — 반죽→쿠키처럼 단계가 올라가는 묘사 (14.1 기각 사유)
2. **코스별 다른 캐릭터 금지** — 코스 구분은 컬러·태그로 (14.2)
3. **사용자 커스터마이징 금지** — 소품은 앱이 자동 노출 (14.2). 쿠키로 의상 해금도 기각됨(12.2)
4. **과한 리액션 금지** — 학습 흐름을 끊는 팝업·애니메이션 (1.2 문제의식, 14.4 톤)
5. **재촉·죄책감 유발 금지** — 삐진 표정, 스트릭 끊김 압박 (12.2에서 스트릭 프리즈 기각한 것과 동일 이유)
