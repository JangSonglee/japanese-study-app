> 검토: 키카쿠(PM) + 대표님 / 시작: 2026-07-20 / 상태: 진행 중
> 화면 순서대로 하나씩 검토하며 결정사항을 누적 기록. 확정분은 이후 아토(디자인)가 와이어프레임에 반영.

## ① 홈 화면 (8) — ✅ 결정됨
- **D-day 카운터 넣는다.** JLPT 코스 컨텍스트에서만 **홈 상단 고정 위젯**(다른 코스로 전환 시 사라짐). Q4 개인화 위젯(스트릭/진도/우표) 순서와는 별개 고정.
- **시험일 입력 = (c) 방식**: 미설정 시 "시험일 설정하기" CTA → 소형 입력 모달(46번).
- **닫기 정책 확정(2026-07-20)**: 닫으면 홈에서 **영구 숨김**이되, 닫는 순간 **"MY › 설정에서 다시 켤 수 있어요"** 안내를 노출한다. 재진입 경로는 두 가지 — ① **MY 설정의 `D-day 위젯 표시` 토글**(35번에 추가) ② **11번 코스 상세에는 계속 노출**(홈에서만 숨긴 것이므로).
- 🔴 **불변 원칙**: D-day는 **선택적 동기 장치이지 학습 전제조건이 아니다.** 미입력·숨김 상태에서도 모든 학습 기능이 정상 동작하며 어떤 흐름도 막지 않는다. (JLPT·여행회화 공통)

## ② 코스 상세·커리큘럼 (11) — JLPT 변형 ✅ 결정됨

### 1. ③의 진행률 UI를 11번에 **통합** (신규 화면 없음)
③에서 설계한 "급수 선택 + 4영역 진행률 리스트"가 곧 **11번 화면의 JLPT 변형**. 별도 허브 화면을 만들지 않음.
→ 11번은 코스마다 형태가 달라지는 화면이 되고, JLPT 버전은 **"영역별 진행률 허브"** 가 된다.

### 2. 구조적 정정 — JLPT는 "과(課)"가 아니라 "세션" 단위
- 기존 11번의 "커리큘럼 목차(1과·2과·3과…)" 메타포는 JLPT에 **맞지 않음**.
  - 단어 = 풀에서 10개씩 뽑는 방식(과 없음) / 문법·독해·청해 = 회독 방식
  - 진도 표시도 "3/12과"가 아니라 **"340/2,250단어" · "2회독째"**
- **용어 확정: JLPT의 "다음 레슨" → "다음 세션"** (PRD 8.1 학습 루프의 JLPT 적용 표현)
- **잠금(🔒) 표시 제거** — 급수 잠금 없음(A안)과 일관. 대신 `추천`/`도전` 라벨.

### 3. 화면 구성 (확정)
```
┌ ← JLPT 시험 대비 ─────────────────┐
│ [상단 요약]  D-day 42  ·  목표 N2  │  ← D-day 홈+코스상세 둘 다 노출(b안)
├───────────────────────────────────┤
│ 급수 선택                          │
│ [N5] [N4] [N3] [N2 추천] [N1 도전] │  ← 잠금 없음
├───────────────────────────────────┤
│ [단어·어휘  ▓▓▓░░░  30%        > ] │
│ [문법       ▓░░░░░  10% 1회독째 > ] │
│ [독해       ▓▓▓▓▓▓ 100% 2회독→ > ] │
│ [청해       ▓▓░░░░  20% 1회독째 > ] │
├───────────────────────────────────┤
│ [ 오답노트 모아보기            > ] │  → 신규 47번 화면
└───────────────────────────────────┘
```
각 영역 탭 → 레슨(14)의 해당 탭으로 바로 세션 시작.

### 4. 발견한 갭 → 화면 신설 ✅
**누적 오답을 앱에서 볼 화면이 없었음**(기존엔 18 토스트 / 20·21 요약 섹션 / 27 날짜별 기록뿐).
45번 오답노트 PDF만 신설하면 "앱에선 못 보는데 PDF로는 받는" 모순 → **47. 오답노트 모아보기 화면 신설 확정**.

## ③ 레슨 혼합형 (14) — JLPT 4탭 구조 ✅ 결정됨

### 탭 구성
**단어·어휘 / 문법 / 독해 / 청해 4탭** (기존 2탭에서 확장). 청해 갭 해소.
**4탭 모두 회독을 통해 오답률이 낮아지는 것을 목표**로 설계.

### 세션 분량 (모듈 1회 진행 단위)
많은 양을 한꺼번에 보여주면 의지가 꺾이므로 **소량 분할**:
| 탭 | 1회 분량 |
|---|---|
| 단어·어휘 | **10단어** |
| 문법 | **5문항** |
| 독해 | **1지문** (급수별 소요시간 편차 → 예상 소요시간 표시 권장) |
| 청해 | **3문항** |

### 오답 처리 (전 탭 공통) ✅
1. 오답이 있으면 **오답만 다시** 보여줌.
2. **2회 연속 오답** 시 → "계속할까요 / 넘어갈까요" **선택 제공** (강제 반복 없음 — PRD 1.3 철학).
3. "넘어가기"를 골라도 **오답노트에 자동 저장**되어 나중에 다시 만남 → 넘어가는 부담 제거.

### A. 단어·어휘 탭 — 카드형 ✅
**카드 앞면: 일본어만 노출.** 카드 내 컨트롤:
- ⭐ **별표** — 단어장 즉시 저장 (항상 활성, PRD 7.1 예외로 명문화)
- **정답 보기** 버튼 — 뜻 공개
- **후리가나만 보기** 버튼
- **발음만 보기** 버튼
- **알고있음** / **모르겠어요** 버튼 (자가판정, 모르겠어요는 다시 보기 대상)

**10단어 완료 후**: 아는 단어 / 모르는 단어 **개수 표시** → **[테스트 시작하기]** + **[다시 보기]** 제공.
**테스트 완료 후**: 오늘의 학습 요약 표시 (오답노트 중요).
- 보완: 자가판정 `알고있음` → 테스트 오답인 단어는 **"안다고 했는데 틀린 단어"로 별도 표시** (가장 강한 학습 신호, PRD 8.2 오늘의 조언 소재).

**진행률**: 급수별 목표 단어 수 대비 수집형 프로그레스바 (예: `N3 단어 340 / 2,250`).
- 분모 = **급수별 신규 어휘** 기준(권장), 목표 수치는 대략치 → 추후 공식 대조·일본인 검증.

### B. 문법 / 독해 / 청해 탭 ✅
- **실제 시험 문제형**으로 제공 (슈슈 리서치: 공식 샘플 "유형" 기반 자체 제작).
- 완료 후 **오늘의 학습 요약** 표시 (오답노트 중요).
- **회독형 진행률**: 세트 완주 = 1회독. 회독을 거듭할수록 오답률·소요시간이 줄어드는 것을 보여줘 반복 동기 부여. 완료 회독은 도장/배지로 누적.

### C. 모듈 진입 시 전체 진행률 UI ✅
급수 선택 + 탭별 진행률 리스트:
```
[ 급수 선택 ▾ ]  ← 예: N2 (현재 수준)
    N5 / N4 / N3  = 자유 선택 (하위 급수)
    N1            = "도전" 라벨 + 레벨 테스트 유도 (잠금 아님)

[ 단어·어휘   ▓▓▓░░░░░  30%              > ]
[ 문법        ▓░░░░░░░  10% · 1회독째    > ]
[ 독해        ▓▓▓▓▓▓▓▓ 100% · 2회독 시작 > ]
[ 청해        ▓▓░░░░░░  20% · 1회독째    > ]
```
- **급수 잠금 없음 (A안 확정)**: 상위 급수도 진입 가능. 현재 레벨엔 `추천`, 상위엔 `도전` 라벨 + "레벨 테스트 해보기" 유도.
  - 이유: 콘텐츠 잠금은 PRD 1.3 "학습 의지를 막지 않는다" · 12장 "전체 콘텐츠 접근" · 10.1 "완전 제한형 기각"과 충돌.
- 진행률 100% 도달 시 **"2회독 시작하기"** 로 자연 전환.

## ④ 단어 탭 → 뜻 팝업 (15) ✅ 결정됨

### 1. 팝업(15) vs 단어 카드(③) — 역할 분리 (중복 아님)
| | 단어 팝업 (15) | 단어 카드 (단어·어휘 탭) |
|---|---|---|
| 상황 | **읽다가** 모르는 단어를 만남 | **외우려고** 단어를 꺼냄 |
| 진입 | 독해 지문·퀴즈·오답노트에서 탭 | 단어·어휘 탭에서 10개씩 제공 |
| 앞면 | 뜻이 바로 보임(읽기 지원) | 일본어만(떠올리기 훈련) |
| 저장 | "단어장에 저장" 버튼 | ⭐ 별표 |
- 읽기 도움 토글: 팝업은 **정답면 성격 → 토글 적용**(기본 ON). 카드 앞면만 예외인 규칙과 일치.

### 2. 급수는 태그가 아니라 **속성**으로 저장 ✅
- 태그 단일 선택 규칙(PRD 6.1)을 지키기 위해 `JLPT`+`N3` 복수 태그는 쓰지 않음.
- **급수(N5~N1)는 단어 속성(메타데이터)** 으로 저장하고, 단어장에서 `JLPT` 태그 선택 시 **급수 하위 필터** 제공.
- → 태그 규칙을 건드리지 않으면서 급수별 복습 가능. (단어장 22번 화면에 하위 필터 UI 필요)

### 3. 저장한 단어 → 학습으로 회귀 (A안 채택) ✅
**문제**: 단어장이 저장·조회·PDF 전용이라, 독해 중 저장한 단어가 다시 학습에 나오지 않음. "저장했는데 왜 안 나오지?"라는 기대 배반.
**해결(A안)**: **단어 카드 세션에 소스 선택 추가** — 단어·어휘 탭에서 `급수 단어` / `내가 저장한 단어` 중 선택.
- 기존 카드 세션을 그대로 재사용하므로 **신규 화면 불필요**(셀렉터만 추가).

## ⑤ 퀴즈 진행 (16) ✅ 결정됨

### 배경 — 기존 3유형이 JLPT 실제 출제 유형을 못 덮음
| JLPT 영역 | 실제 출제 유형 | 기존 3유형 커버 |
|---|---|---|
| 문자·어휘 | 한자읽기/표기/문맥규정/유의어/용법 | ✅ 객관식·짝맞추기 |
| 문법 | 문법형식 판단, 글의 문법 | ✅ 객관식 |
| 문법 | **문장 만들기(순서배열)** | ❌ → 신설 |
| 독해 | 내용이해/주장이해/정보검색 | ✅ 지문+객관식 |
| 청해 | 과제이해/포인트이해/즉시응답 | ❌ → 신설 |

### 결정
1. **청해형 퀴즈 신설** ✅ — 음성 재생 + 객관식 + 다시듣기. (기존 "받아쓰기"는 *쓰는* 유형이라 청해 대체 불가)
2. **순서배열형 퀴즈 추가** ✅ — 단어 조각을 순서대로 배열해 문장 완성. JLPT 문법 대표 유형.
   → 둘 다 **16번의 서브 유형으로 편입** (3종 → **5종**), 새 번호 부여하지 않음.
3. **단어 카드 10개 후 테스트 형식** ✅ — **(가) 객관식(뜻 고르기) 기본 + "모르겠어요" 표시한 약한 단어만 받아쓰기**
   → 빠른 진행을 유지하면서 약한 단어만 강하게 훈련.

### 입력 방식 확정 (2026-07-20 추가) ⭐
**문제**: 받아쓰기는 일본어 IME가 필요한데, **IME가 없는 사용자가 다수**이고 설치해도 초보자는 로마자→가나 변환을 모른다 → **이중 진입장벽**.
**해결**: OS 키보드에 의존하지 않고 **앱 내장 가나 키보드**를 제공한다.
| 단위 | 입력 방식 | 근거 |
|---|---|---|
| **단어** 받아쓰기 | **앱 내장 히라가나/가타카나 50음 키보드** | IME 불필요. 가나 배열을 익히는 **학습 효과도 큼**. 받아쓰기는 단어·어휘 테스트 전용이라 **가나 수준이면 충분**(한자 입력 불필요) |
| **문장** 단위 | **낱말카드 배치** | 타이핑 부담이 큼. 스피킹 대체 모드와 **컴포넌트 공유** |
> 와이어프레임 16번에 이미 "가상 키보드 영역" placeholder가 있었으므로, 이를 **내장 가나 키보드로 확정**하는 것으로 해소됨.

### 스피킹형 퀴즈 — 자가판정 방식 (2026-07-20 확정) ⭐
**유사도 점수·판정 바를 쓰지 않는다.** TTS 발음 비교는 억양·속도·마이크 환경에 따라 오판이 잦고, 낮은 점수는 좌절만 남긴다 → **죄책감을 주지 않는** 앱 철학(1.3, 14.4)과 충돌.
- 구조: `[🎤 녹음]` → `[▶ 내 발음 듣기]` `[다시 녹음]` `[넘어가기]` — **본인이 듣고 판단해서 넘어감**
- 단어 카드의 `알고있음/모르겠어요` **자가판정과 같은 패턴** → 규칙 통일
- **"지금 말할 수 없는 상황이에요"** 텍스트 버튼 → **낱말카드 배치 모드**로 전환 (지하철·심야 등 실제 모바일 상황 배려, 이탈원인 대응)
- **마이크 권한 거부 시에도 자동으로 낱말카드 모드 폴백**
- ⚠️ 정오 판정이 없으므로 **오답노트에 담지 않음**(2회 연속 분기 미적용)

### 부수 정리 — 받아쓰기의 역할 재정의
JLPT는 전 영역 객관식(마크시트)이라 실제 시험에 받아쓰기가 없음. 그러나 학습 효과는 큼.
→ **받아쓰기 = 단어·어휘 학습 테스트 전용**(암기 강화), **문법·독해·청해 = 실제 시험 유형만** 사용.

### 오답 처리 일관성
③에서 정한 "오답만 재노출 → **2회 연속 오답 시 계속/넘어가기 선택**"은 **5개 유형 전부에 동일 적용**. 청해도 동일(다시 듣기 후 재시도).

## ⑥ 정답·오답 피드백 (17) ✅ 결정됨

### 1. 해설 3단 구조 — 전면 채택 ✅
시험 대비 코스는 "왜 이게 답인지"가 학습의 본체이므로, JLPT 피드백은 3단으로 구성:
1. **정답**
2. **왜 정답인지** (문법: 해당 문형 / 독해: 근거 위치 / 어휘: 음독·훈독 구분)
3. **오답 선택지가 왜 틀렸는지** (선택지별)
→ 다른 코스보다 해설 영역을 크게 배치.

### 2. 청해 오답 시 **스크립트(전사) 제공** ✅
오답 시 다시듣기 + **스크립트 텍스트** 제공. 음성만으로는 학습이 끊기므로 청해 학습의 핵심.

### 3. "2회 연속 오답" 분기 UI를 17번에 **통합** ✅ (별도 화면 없음)
17번이 상태 2종을 갖는다:
```
[1회 오답]  정답·해설 + [계속하기]
[2회 연속]  정답·해설 + [다시 풀기] [넘어가기]
                     ↳ "넘어가도 오답노트에 남아요" 안내
```

### 4. 기존 규칙 반영 확인
- 읽기 도움 토글: 피드백=정답면 → **적용(기본 ON)** ✅
- **단어 탭 저장**: PRD 7.3 적용 범위에 "퀴즈 문제 및 오답노트" 포함 → **해설 속 단어도 탭 저장 가능**해야 함 (현재 와이어프레임에 미표기 → 아토 반영 필요) ⚠️
- 캐릭터: 안경 쓴 토모(14.2) + 관찰자 톤(14.4) ✅

### ⚠️ 콘텐츠 제작비 영향 (슈슈·콘텐츠 단계 전달 필요)
위 1·2 결정은 원자료 수집 범위를 넘어 **제작 부담을 크게 늘림**:
- 문항마다 해설 3종(정답 근거 + 오답 선택지별 이유) 작성 필요
- **모든 청해 음성에 스크립트 텍스트** 필요 (음성 자체도 자체 제작 — 성우/TTS)
→ MVP 범위 산정 시 반드시 반영할 것. 급수·영역 우선순위(PRD 13장: 비즈니스·JLPT·여행회화 우선)에 따라 단계적 제작 권장.

## ⑦ 오답노트 — 알림(18) + 모아보기(47 신설) ✅ 결정됨

### 1. 토스트 정책 변경 ✅
**문제**: 오답마다 토스트가 뜨면 단어 10개 중 5개 오답 시 토스트 5번 → PRD 1.2(흐름 방해 문제의식)·14.4(과묵한 관찰자)와 충돌. "넘어가기" 경로는 17번에서 이미 안내하므로 중복.
**결정**: 문항별 토스트 폐지 →
- 문항별 저장은 **17번 피드백 화면에 인라인**으로 조용히 표시("오답노트에 담았어요")
- 토스트는 **세션 종료 시 1회 요약**("오늘 8개가 오답노트에 담겼어요")
→ 18번 역할이 "문항별 토스트" → **"세션 종료 요약 알림"** 으로 변경.

### 2. 오답노트 "졸업" 규칙 — (A) 채택 ✅
**2회 연속 정답 시 "이제 알아요"로 이동** — 목록에서 내려가되 **삭제하지 않음**(복습 가능).
- ⚠️ 용어 변경(2026-07-20): 초안의 **"익힘"은 만들어낸 말이라 모호**하다는 지적 → **"이제 알아요"** 로 확정(사용자 목소리, 토모의 담백한 톤과 정합).
- 47번 필터 칩: **`[전체] [아직 헷갈려요] [이제 알아요]`** → 별도 용어 설명 없이 바로 이해되고, "졸업 항목 재열람 경로"도 이 칩으로 해결됨.
- "2회 연속"은 오답 분기 기준(2회 연속 오답)과 **대칭** → 규칙을 하나로 기억.
- 1회 정답 졸업(찍어서 맞힌 것도 졸업)과 무한 누적(목록 비대화)을 모두 회피.

### 3. "넘어가기" 항목 **구분 표시** ✅
틀린 것(`✕`)과 넘어간 것(`⤼`)을 시각적으로 구분. 성격이 다름(틀림 vs 미해결 보류).

### 4. 47번 오답노트 모아보기 구성
```
┌ ← 오답노트 ──────────── [읽기도움 ON] ┐
│ [전체][JLPT][여행][비즈]…              │ ← 코스 태그
│ JLPT ▸ [N3▾] [단어][문법][독해][청해]  │ ← 급수·영역 하위 필터(④ 속성 방식)
├──────────────────────────────────────┤
│ ✕3  …                      [다시풀기] │ ← 틀린 횟수
│ ⤼   …(넘어감)              [다시풀기] │ ← 구분 표시
├──────────────────────────────────────┤
│ [ 전체 다시 풀기 ]  [ ⤓ PDF (우표 5) ]│ → 45번
└──────────────────────────────────────┘
```
- 정렬: **틀린 횟수 많은 순** 기본(약한 것부터), 최근순 토글 제공
- 읽기 도움 **기본 ON** (PRD 8.4가 오답노트를 명시)

## ⑧ 우표 적립(19) + ⑨ 오늘의 학습 요약(20/21) ✅ 결정됨

### 1. JLPT "오늘의 학습" 정의 (Q3 연동) ✅
우표 적립 단위가 "오늘의 학습"인데 JLPT에선 그 단위가 미정이었음 → Q3(하루 학습 시간, PRD 10.2)로 정의:
| Q3 응답 | 오늘의 학습 | 예상 소요 |
|---|---|---|
| 시간 적음(10분 이하) | **1세션** | 3~6분 |
| 보통(10~30분) | **2세션** | 8~12분 |
| 많음(30분+) | **3~4세션** | 15~25분 |
→ 정해진 세션 수를 채우면 **우표 1개 + 요약 화면(20/21)**.

### 2. 세션 종료 알림(18) ↔ 요약 화면(20/21) 중복 해소 ✅
"오늘의 학습 = 1세션"인 사용자는 둘이 동시에 발생 → 겹침.
- 세션 종료 시 **오늘의 학습이 남아 있으면** → 18번 토스트
- 세션 종료 시 **오늘의 학습이 끝났으면** → 토스트 생략, 바로 **20/21 요약 화면**

### 3. 요약 화면에 JLPT 정보 추가 ✅ — 단, **PDF에는 제외** ⚠️
**화면에 추가**: 회독·진행률 변화("N3 문법 45→50문형, 2회독째"), D-day, 오늘의 조언 강화
(조언 소재: "조사 문제에 오답이 몰렸어요", **"안다고 했는데 틀린 단어 3개"**)

> 🔴 **대표님 지시 (전 PDF 공통 원칙)**: 요약 화면을 PDF로 받는 사용자에게 **불필요한 요소까지 다운받게 하지 말 것.**
> **화면 표시 항목 ≠ PDF 포함 항목**을 명확히 분리한다.
> - **PDF 포함**: 오늘 배운 단어 / 오답노트 추가분 / 오늘의 조언 — **"다시 볼 학습 내용"만**
> - **PDF 제외**: 회독·진행률, D-day, 우표 진행바 등 **앱 내 상태·게임화 요소** (종이에선 무의미하고, 인쇄 시점에 박제되면 오히려 혼란)
> - 이 원칙은 요약 PDF뿐 아니라 **오답노트·단어장·독해 PDF 전부에 동일 적용**.

1. **PRD 8.4 읽기 도움 토글 적용 범위 보완** ✅결정

   - **정답면 · 단어목록 · 오답노트 · PDF** = 토글 적용 (기본 ON 유지)

2. **PRD 7.1 원탭 즉시저장 기각의 예외 명문화** ✅결정
   - 학습 카드 내 ⭐별표는 **항상 활성**. 카드는 뜻 확인이 구조적으로 전제되므로 원탭 기각 사유("뜻 미확인 저장")가 적용되지 않음.
