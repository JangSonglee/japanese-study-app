# 토모 캐릭터 배치 — 기획 분석 (2026-07-28)

> 근거: PRD **14.2 / 14.2.1**(등장 조건, 2026-07-23 확정) · 14.4(과묵한 관찰자) · 14.5(토모의 쪽지)
> 목적: 확정된 규칙을 **현재 FE(본편 골격)에 매핑**해 감사하고, 다음 화면들의 배치를 예약한다.

## 1. 원칙 요약 (이미 확정 — 새로 정하지 않음)
**판별 기준 한 줄(14.2.1)**: *판단하거나 집중하는 순간엔 없고, 결과를 마주하거나 쉬는 순간엔 있다.*

- ❌ **「하는 중」**: 카드 앞면 · 퀴즈 푸는 중 · 지문 읽는 중 · 단어장/설정(도구) · 🔴 **결제·구독 전 구간(예외 없음)**
- ✅ **「마주하는/쉬는」**: 홈 · 결과·오답 피드백(판단 끝난 뒤) · 우표/편지 · 토모의 쪽지 · 오프라인 진입 · MY 홈 · 추천결과/첫학습 · 오답노트 모아보기 · **빈 상태 화면**
- **등장 조건**: ① 말 걸지 않는다(문구는 화면이 나름) ② 세로 공간 추가로 쓰지 않는다
- **밝기=표정**: 기본 은은/재접속 반짝/오답·복습 아래를 비춤. 🔴 **밝아짐은 「새 쪽지」 전용 신호**
- **비주얼**: 외곽선 없는 파스텔 블롭(14.3). 코스 구분은 토모가 아니라 컬러·태그로.

## 2. 현재 FE 감사 (지금 만든 화면)
| 화면 | 토모 현재 | 규칙 | 판정 |
|---|---|---|---|
| **홈** | 있음(hero, 평소 밝기) | ✅ 마주/쉼 | **맞음.** 단 「밝아짐+탭→쪽지」는 미구현(쪽지 기능 50 없음) |
| **단어 세션 앞면** | 없음 | ❌ 하는 중 | **맞음** — 뜻 떠올리는 순간, 시선 뺏으면 안 됨 |

**결론**: 현재 배치는 규칙과 어긋난 곳이 없다. 조정 후보는 **MY 홈(토모 도입)** 하나, 예약 항목은 **홈 토모 탭화 + 빈 상태**다.

## 3. 권고 (우선순위)
1. 🟡 **MY 홈에 토모(선택)** — 14.2.1이 MY를 ✅(쉬는 화면)로 본다. 현재 게스트 아바타('게') 대신 **작은 토모(평소 밝기·말 없음)**를 두면 "쉬는 자리의 동반자"가 산다. 로그인 후엔 프로필과 공존(토모는 상단 브랜드, 아래 계정 정보).
2. 🔑 **홈 토모 = 탭 타깃으로 예약** — 쪽지 기능(50) 붙을 때 홈 토모가 **밝아짐 + 탭 → 토모의 쪽지** 진입점이 된다(14.5). 지금 홈 토모를 그 자리에 그대로 두었으니, 쪽지 붙일 때 `onPress` + 밝기 상태만 얹으면 됨.
3. 📋 **빈 상태 화면에 토모(예약)** — 단어장·편지함·오답노트가 비었을 때 토모 필수(14.2.1: "빈 화면에 사람이 없으면 버려진 느낌"). 아직 미구현 → 그 화면 만들 때 반영.
4. 🔦 **비추는 대상 매핑(14.2)** — JLPT 결과·요약에서 토모가 **연필**을 비추는 연출은 정식 아트(아토) 확보 후. 현재는 임시 스탠드인이라 소품 없음(문제 아님, 예약).
5. 🚫 **확산 금지선** — About에 토모를 둔 것은 브랜드 화면이라 정당하나, **설정·단어장·결제류로 번지지 않게** 한다(도구/영업 자리엔 없음, 14.2.1·결제 예외 없음).

## 4. 미해결 / 다음
- MY 홈 토모 도입 여부 = 대표님 판단(선택). 도입 시 게스트 아바타 대체.
- 홈 토모 탭화·빈 상태 토모·소품 연출은 **각 기능(쪽지·단어장·정식 아트) 구현 시점**에 함께.
- 정식 토모 아트가 나오면 `Tomo.jsx`(임시 스탠드인) 한 곳만 교체 → 홈·요약·About·MY 동시 반영.
