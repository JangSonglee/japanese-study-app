> 목적: 지금 빌드를 켜고 **뭐가 정상이고 뭐가 의도적 보류인지** 바로 구분. 🔴 **빠진 부분은 잘못 구현이 아니라 계획된 수직 슬라이스**다(진행상태.md 근거).

## 0. 이 빌드의 성격 (왜 이렇게)
- **수직 슬라이스**: "지금 데이터로 진짜 되는 것(단어·문법)부터 홈→세션까지 끝까지 걸리게"만 만들었다(대표님 승인).
- **온보딩·로그인·다른 탭·진행률**은 일부러 뺐다 — 데이터/기능이 없어 넣으면 빈 화면이 되기 때문(철학: 미완성 미노출).
- 그래서 **일부 요소는 「정직한 보류 표시」로만** 보인다(아래 6장). 이건 버그가 아니다.

## 2. ✅ 지금 되는 것 — 테스트 시나리오 (스텝 → 기대 결과)

### A. 홈 → 학습 진입
| 스텝 | 기대 결과 |
|---|---|
| 앱 첫 화면 | 토모(등불) + "오늘도 왔네요." + **「오늘의 학습 시작」** 버튼 + 우상단 **MY** |
| 「오늘의 학습 시작」 탭 | **코스 목록**으로 이동 |
| 코스 목록 | **JLPT만 활성**(› 화살표), 여행회화·비즈니스·뉴스·전래동화는 **「곧 열려요」**(비활성) |
| JLPT 탭 | **JLPT 허브**로 이동 |

### B. 급수 선택 (셀렉트 + 바텀시트)
| 스텝 | 기대 결과 |
|---|---|
| 허브의 **급수 셀렉트 박스**(「JLPT N5 · 입문 · ⌄」) 탭 | 아래에서 **바텀시트**가 올라옴 (N5~N1 + 난이도: 입문·초급·중급·중상급·고급) |
| 예: **N3** 선택 | 시트 닫히고 셀렉트가 **「JLPT N3 · 중급」**으로, 영역도 N3으로 갱신 |
| 스크림(어두운 배경) 탭 | 시트 닫힘 |

### C. 단어 세션 (실 Supabase)
| 스텝 | 기대 결과 |
|---|---|
| 영역 **「단어·어휘」** 탭 | **실 DB에서 그 급수 단어 12장** 로드(예: N3 단어). 상단 「N3 · 단어 · 1/12」 |
| 카드 앞면 | **좌상단 일본어**(한자) + 중간 **이미지 슬롯**(「이미지 예정」 점선) |
| **「후리가나 보기」** 탭 | 한자 위에 읽기 표시(**본문 0px 점프**), 라벨 「후리가나 끄기」로 |
| **「한글 발음 보기」** 탭 | 한글 발음 줄 표시(공간 항상 확보), 후리가나와 **독립** |
| **「뜻 보기」** 탭 | 뜻·예문만 열림 — 🔴 **후리가나·발음은 안 켜짐**(완전 독립) |
| 「알고있음/모르겠어요」로 12장 완주 | **세션 요약**(토모 + 아는/모르는 개수 + 수집형 진행바 + 다시 보기/테스트 시작하기) |
| 상단 **‹ 뒤로** | 허브로 복귀 |

### D. 문법 세션
| 스텝 | 기대 결과 |
|---|---|
| 영역 **「문법·문형」** 탭 | 실 DB 문법 카드. 앞면 = **문형 + 접속**(예 「동사 て형 + から」) |
| 「뜻 보기」 | 뜻 + 용법(politeness) + 예문 |

### E. MY · 설정 · 서비스 정보
| 스텝 | 기대 결과 |
|---|---|
| 홈 우상단 **MY** | 게스트(토모) + 메뉴(설정·서비스 정보) |
| **설정** | 읽기 도움 기본값 토글 2개(후리가나·한글 발음) |
| **서비스 정보** | 서비스 개요 + 하단 **출처(Tanos · CC BY · tanos.co.uk 링크)** |

### F. 테마
- 폰 밖 **다크/라이트 토글** → 전 화면 라이트/다크 정상, 대비 유지.

## 3. 🅿️ 의도적으로 뺀 것 (보류 — 이유 있음, 버그 아님)
| 뺀 것 | 이유 |
|---|---|
| **온보딩**(스플래시·소개·가입·진단·추천결과·레벨테스트) | 로그인(Auth) 필요 — 미구축 |
| **급수 「추천/도전」 태그** | 사용자 레벨(진단 Q2/레벨테스트)이 있어야 붙는다 → 온보딩 대기(결정은 확정됨, JLPT_플로우 A안) |
| **로그인** → 스트릭·우표 적립·**진행률 누적**·단어장 저장 | 서버 원장 쓰기 = 로그인 필요. 그래서 홈에 스트릭 없음, 「진행률은 로그인 후 표시」 |
| **하단 5탭 바**(단어장·번역 탭) | 콘텐츠 없어 빈 탭 방지 — 스택 네비만 |
| **단어 이미지** | 슬롯만(「이미지 예정」). 이미지 PNG는 `public/images/vocab/`에 넣으면 물림(image_url 스키마 추가 후) |
| **세션 = 급수 첫 N개** | 진짜 spaced-repetition(SRS) 미구현. 지금은 「화면이 데이터를 문다」 검증용 |
| **테스트/퀴즈**(16·17)·정답/오답 피드백 | 문항 콘텐츠(questions) 미제작 |
| **검색 탭 · TTS 음성 · 독해/청해** | 별도 트랙 |

## 5. 오해 방지 — 「이건 보류 신호」 읽는 법
앱에서 아래 문구를 보면 **정상(보류)**이다:
- **「곧 열려요」** = 코스 단위 미완성(코스는 있다는 사실만 노출)
- **「진행률은 로그인 후 표시」** = 로그인 붙으면 채워질 자리
- **「이미지 예정」** = 이미지 파이프라인 대기
- **「독해·청해는 준비되는 대로」** = 콘텐츠 수집 대기
- **게스트 / 「로그인은 곧 열려요」** = Auth 대기

## 6. 더 채워서 테스트하고 싶으면
특정 조각만 콕 집어 채울 수 있다(공수 순):
- **급수 추천/도전 태그** (임시 레벨값으로 시연 — 온보딩 붙으면 값만 교체) · 반나절
- **진행률 로컬 추적**(localStorage 만난 단어 수) · 반나절
- **온보딩 슬라이스**(소개→진단→추천결과, 로그인 없이 로컬) · 1~2일
- **하단 탭 바 + 단어장(로컬 저장)** · 1~2일
→ 원하는 걸 고르면 그것만 만들어 테스트 가능하게 함.
