# 1그룹 — 구문·어휘형 (여행 회화 + 비즈니스) ✅ 결정됨

## 공통 결정

### 1. 해설 축 변경 ✅
JLPT의 "문법적 정오" 해설 → **"상황 적절성·정중도"** 중심으로 전환.
- 예: "이 표현은 손윗사람에겐 실례입니다", "이건 식당에선 쓰지 않습니다"
- **3단 해설(오답 선택지별 이유)은 축소** — 시험이 아니므로 과잉이고 제작비만 증가.

### 2. 진행률 = **표현 수집형** ✅
JLPT 단어 탭과 같은 수집형(카테고리별 표현 N개 중 M개 익힘). 회독형은 쓰지 않음.

### 3. 스피킹 퀴즈 **우선 도입** ✅
두 코스는 실제로 **말해야 하는** 표현을 다루므로 TTS 발음 비교 퀴즈를 우선 적용.
→ 16번 퀴즈 서브 유형에 **스피킹형** 추가 (총 6종). PRD Should 유지하되 이 두 코스에서 먼저 적용.
- JLPT는 말하기 시험이 없어 미적용.

### 4. 학습 단위가 "표현(문장)" ✅
`단어 → 뜻`이 아니라 `상황 + 문장 → 뜻·발음`. **음성 재생 비중이 큼**.

## ✈️ 여행 회화 고유

### 5. 분류 축 = 상황 **8카테고리** (급수 아님)
JLPT의 급수 셀렉트 자리에 **여행 동선 순서** 배치:
공항·입국 → 교통·길찾기 → 숙소 → 식당·주문 → 쇼핑·계산 → 편의점·약국 → 온천·료칸 → 긴급상황
- **잠금 없음** (급수 잠금 폐기 원칙과 동일). "여행이 코앞이면 식당부터" 선택 가능.

### 6. 일상표현 TIP = **각 카테고리에 섞기** ✅ (PRD 4.1 개정)
- 별도 섹션으로 떼지 않고 **카테고리마다 그 상황에 맞는 TIP을 섞어 배치**
- 단 **`TIP` 라벨 유지 + "TIP만 모아보기" 필터** 제공
- **PRD 4.1을 옵션 B → 옵션 B′로 개정함.** 원래 옵션 B의 채택 이유("완전 통합형은 여행 계획자와 일상표현 관심자를 구분 못함")는 **라벨 유지 + TIP 필터**로 해소. 라벨 없이 섞는 옵션 A는 여전히 미채택.

### 7. 여행 D-day 도입 ✅ — 단, **선택 사항**
페르소나1이 "여행 전까지" 익히려는 사람(설문 90%)이므로 출발일 D-day가 강한 동기.
- **46번 시험일 설정 모달 재사용** (JLPT 시험일 ↔ 여행 출발일)
- 🔴 **필수 제약**: **D-day를 입력하지 않아도 학습에 아무 지장이 없어야 함.** 미입력 시 위젯 자리에 설정 CTA만 노출되고, 학습 흐름·기능은 전혀 막히지 않음.
- → **일반 원칙**: D-day는 **선택적 동기 장치이지 학습 전제조건이 아니다** (JLPT도 동일 적용).

### 8. 카메라 번역과 연결된 유일한 코스
PRD 5.2 "이 표현, 여행 회화 3과에서 배운 표현이에요" 연계는 이 코스에만 존재.
→ 31번(인식 결과–매칭됨)이 여행회화 콘텐츠와 물려야 함.

# 2그룹 — 읽기형 (뉴스·시사 + 전래동화) ✅ 결정됨

## 전제: 두 코스의 콘텐츠 총량이 정반대
| | 뉴스·시사 | 전래동화 |
|---|---|---|
| 콘텐츠 | **무한**(계속 추가) | **유한**(이야기 세트) |
| 진행률 100% | 불가능 | 가능 |
| 시의성 | 있음 | 없음 |

## 1. 진행률 프로그레스바 폐기 → **"N회 읽음"** ✅
```
| 곰 세마리          3회 읽음 · 7/18  > |
| 아기돼지 삼형제    5회 읽음 · 7/12  > |
```
**두 코스 동일한 항목 UI.** 채택 이유:
- 뉴스의 **분모 문제가 사라짐**("2회 읽음"은 전체 개수를 몰라도 성립)
- 읽기는 "끝냈다"가 무의미 — 한 번 훑음과 세 번 정독은 다른데 프로그레스바는 구분 못 함
- 프로그레스바는 "빨리 채워라" 신호 → *끝없는 학습* 철학(14.2)과 충돌. 회독 수는 **깊이**를 보여줌
- JLPT 회독 모델과 규칙 통일
- **"최근 읽은 날짜" 병기** — 뉴스의 시의성 보완

### 목록 구성만 코스별로 다름 (항목 UI는 동일)
- **전래동화**: 전체 이야기 목록 + 회독 수
- **뉴스**: **최근 기사 목록 + "읽은 기사" 필터** (무한이라 전체 조망 불가)

## 2. "읽음" 판정 = **`[읽기 완료]` 버튼** ✅ (이해 퀴즈 강제 폐지)
- 지문 하단에 **`[읽기 완료]`** + **`[이해 확인해보기]`** 병행
  - 그냥 읽고 싶으면 읽기 완료 → **회독 +1**
  - 확인하고 싶으면 퀴즈 → **오답노트 루프 유지**
- **퀴즈는 강제가 아니라 선택** — "편안히 읽기"와 "루프 유지"를 동시에 확보. 강제하지 않는 철학과 정합.
- **버튼을 지문 맨 아래 배치** → 끝까지 스크롤해야 눌리므로 별도 검증 로직 불필요.

### 퀴즈 제작 부담은 유형 분리로 해결
| | 뉴스(무한) | 전래동화(유한) |
|---|---|---|
| 퀴즈 | **자동 생성형**(지문 속 단어 객관식·빈칸 채우기) | **수작업 내용 이해 퀴즈** |

## 3. 지문 노출 방식 ✅
- **원문 먼저 노출**. 단 "원문" = *신문 원문*이 아니라 **"내가 고른 난이도의 일본어 텍스트"**
  - N4 학습자에겐 EASY판이 그 사람의 원문 / N1에겐 일반 기사가 원문
  - 공통점은 **"해석 없이 일본어를 먼저 본다"** → PRD 4장 "EASY→원문 순서"와 충돌 없이 공존
- 상단 편의 토글: **`[후리가나·발음]` `[해석]` 둘 다 기본 OFF** (PRD 8.4 통합 원칙)

## 4. 하단 메모("꼭 알아야 할 단어·문법") ✅
| | 제공 여부 | 이유 |
|---|---|---|
| **뉴스** | ❌ **제공 안 함** | 단어 탭 팝업(15)이 이미 그 역할 / 자동 추출은 품질 리스크+개발비 / "가볍게 오늘의 일본어를 읽는" 경험을 무겁게 함 |
| **전래동화** | ✅ **제공** | 고어·문학적 표현 설명이 실제로 필요, 유한 세트라 수작업 가능 |
→ 뉴스 메모 자동 추출 개발 **불필요**해져 범위 축소.

## 5. 전래동화 3단 난이도 ✅
이야기별 **리라이트(N5~N4) / 표준(N3) / 원문(N2~N1)** 3단 제공 (슈슈 리서치 매핑).
- ⚠️ 자체 리라이트는 **승인 대기 중**이라 초기엔 일부 이야기만 3단 완비.

## 6. 읽기형의 단어 복습 경로 ✅
코스 전용 단어 탭을 만들지 않음. **④에서 정한 "내 단어장 소스 카드 세션"으로 충분**.
읽다가 저장한 단어를 나중에 카드로 복습 → 읽기형과 카드 학습이 자연스럽게 연결.

## 앱 전체 규칙 변경 (PRD 반영 완료)
- **PRD 8.1** 읽기형 정의 → `[읽기 완료]` / `[이해 확인해보기]` 병행, 퀴즈 선택제
- **PRD 8.4** 토글 **통합 원칙** 신설:
  > "먼저 스스로 부딪히는 면(문제면·원문면)에서는 읽기 도움이 기본 꺼짐. 도움은 사용자가 켠다."
  - 기본 OFF: 학습 카드 앞면 / 읽기형 지문 첫 노출
  - 기본 ON: 정답면·단어목록·오답노트·PDF
  - **`[해석]` 토글 신설, 기본 OFF** (후리가나는 읽기를 *돕고*, 해석은 읽기를 *대신*하므로 비대칭)
