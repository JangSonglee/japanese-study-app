## 배경 — 모델이 한 번 바뀌었다

2026-07-29 IA 플로우 검토 세션에서 우표 모델을 **소비형 → 컬렉션형**으로 바꾸기로 확정했다.
그러나 그 후속 수치(편지 마일스톤, PDF 무료 월 N회)가 미정으로 남았고, PRD·project_master·플로우
문서는 여전히 **옛 소비형 모델**(우표 7/5/10 소비, 350장 증정)을 서술하고 있었다. 이 문서는 그
공백을 메우고, 옛 서술과의 충돌을 정리하기 위한 근거 기록이다.

| | 옛 모델 (소비형, ~2026-07-29 이전) | 새 모델 (컬렉션형, 확정) |
|---|---|---|
| 우표 | PDF 받을 때 **소비**(요약7·오답5·단어장10) | **소비하지 않고 누적**(컬렉션) |
| 편지 | = 요약 PDF (우표 7장으로 교환) | 우표 N장 모으면 오는 **감성 리워드**(PDF와 분리) |
| PDF | 우표 소비 + 일부 월 3회 | **우표와 무관 · 무료 월 N회** |
| 구독 가치 | 우표 350장 대량 증정 | **기능**(광고 제거 · PDF 무제한). 350장 증정 **폐지** |

## 확정 수치

### ① 편지 마일스톤 — 우표 14장 → 편지 1통 (온보딩 가속 포함)

- 적립: "오늘의 학습" 하루 완료당 **우표 1장** (모듈 단위 아님, 기존 유지).
- 마일스톤: **첫 편지는 우표 3장**, **두 번째 편지부터 14장 간격**.
  - 예: 누적 3장 → 1통, 17장 → 2통, 31장 → 3통 …
- 우표는 소비하지 않고 계속 쌓이며, 편지도 **모으는 것**(편지함, PRD 8.3).

**근거**
- 새 모델에서 편지는 유틸(PDF)이 아니라 **감성 리워드**다. 너무 흔하면 감동이 옅어지고, 너무
  멀면 동기가 끊긴다 → 정기 간격은 **약 2주(월 2통)**로 희소성과 동기를 함께 지킨다.
- 온보딩 가속(첫 3장): 신규 사용자가 **3일 안에 첫 편지**를 받아 초반 성취·리텐션을 확보. 이후엔
  14장 균일로 돌아가 리워드 인플레를 막는다.
- 철학 정합(1.3 "학습 의지를 꺾지 않고 북돋는다"): 편지는 재촉이 아니라 **꾸준함에 대한 보답**이다.

### ② PDF 무료 다운로드 — 종류 무관 통합 월 5회

- 요약·오답노트·단어장·독해 PDF **합산 월 5회**, 매월 1일 리셋.
- 구독자 무제한. **우표와 완전 무관**(우표로 PDF를 사지 않는다).
- 열람·학습은 언제나 무제한 — **결과물 소장(PDF)에만** 상한(12.1 원칙 유지).

**근거**
- 통합 단일 규칙 = 사용자가 이해하기 쉽다("이달 PDF 5번"). 종류별 쿼터는 설명이 복잡하고
  구독 유인이 약하다.
- 헤비 유저는 자연스럽게 구독으로("기회는 주되 약간의 불편함"). 무료 5회는 라이트 유저의
  실사용을 대부분 커버해 불쾌한 차단이 되지 않는다.

### ③ 구독 가치 = 기능

- 광고 제거 + PDF 무제한. 우표 대량 증정(350장)은 **폐지** — 우표/편지는 몰입 리워드일 뿐
  수익 수단이 아니다. 우표를 소비/증정하지 않으므로 구독과 우표는 분리된다.
