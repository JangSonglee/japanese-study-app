# 실제 홈(위젯) FE 구현 — 설계

- 날짜: 2026-07-30
- 대상: `개발/프론트엔드_무스부/tomori-app/src/screens/HomeScreen.jsx`
- 근거: 기획 화면 8번(홈 · 스트릭·오늘의 학습·진도·위젯, PRD 10.4~10.5) + Figma 재현(07 페이지)

## 1. 목적 / 배경

현재 `HomeScreen`은 FE 수직 슬라이스용 **미니멀 진입 화면**(토모 + "오늘의 학습 시작" 버튼)이다.
주석의 기존 결정(2026-07-28): "스트릭·진도 위젯은 로그인 전 데이터가 없어 **가짜 위젯을 두지 않고 정직하게 생략**".

대표님 요구(2026-07-30): 홈이 홈다워야 한다 — 이어서 학습·스트릭·D-day·진도·우표·조언 위젯.
Figma로 위젯 홈을 확정했다. 이를 실제 FE로 구현한다.

## 2. 범위 결정 (대표님 2026-07-30)

- **데이터 = 데모 목업으로 완성형.** Figma에서 본 값(7일 연속·D-42·N3 34% 등)을 상수로 두고 홈을 완성한다.
  각 위젯에 `// TODO: 실데이터(인증/DB) 배선` 주석을 남긴다.
- 🔴 **기존 "정직한 생략" 원칙을 이번 한정 유보**: 지금은 슬라이스/데모 단계라 완성된 홈 모습을 우선한다.
  인증(Google OAuth)·학습기록 DB가 붙으면 목업 → 실데이터로 교체(위젯별 배선 지점 명시).
  위젯별 데이터 출처: D-day·이어서학습=로컬 저장 가능 / 스트릭·진도·우표·조언=학습기록(인증·DB).

## 3. 화면 구성 (위→아래, ScrollView)

1. **앱바**: "토모리" | 코스 전환 pill(`JLPT ▾`) | MY pill
2. **인사**: 토모(`shine`, 작게) + "오늘도 왔네요, 송이님" / "일곱 밤째 함께 불을 켰어요."
3. **스트릭 | D-day** (2컬럼):
   - 스트릭: "연속 학습" + "7일"(brandText) + 주간 점 7개(5 채움)
   - D-day: "JLPT N3 시험" + "D-42"(jlpt) + "12월 3일"
4. **이어서 학습** (강조 — brand 1.5px 테두리): "이어서 학습" 라벨 + "JLPT · N3 · 독해" + 진행바(3/12) + [이어서 하기] 버튼(action)
5. **진도 | 우표** (2컬럼):
   - 진도: "N3 진도" + "34%" + 미니 바
   - 우표: "우표" + "12 / 20" + 미니 바 + "다음 편지까지 8장"
6. **오늘의 조언**: 토모(`intellectual`, 작게) + "오늘의 조언" + "어제는 동사 활용에서 좀 헤맸어요. 오늘 그 부분 다시 볼까요?"

## 4. 데이터 (데모 목업 상수)

파일 상단에 `HOME_DEMO` 상수:
```js
const HOME_DEMO = {
  user: '송이',
  streak: { days: 7, week: [true, true, true, true, true, false, false] },
  dday: { label: 'JLPT N3 시험', d: 42, date: '12월 3일' },
  cont: { course: 'JLPT', level: 'N3', area: '독해', route: 'readingSession', done: 3, total: 12 },
  progress: { level: 'N3', pct: 34 },
  stamp: { have: 12, need: 20 },
  advice: '어제는 동사 활용에서 좀 헤맸어요. 오늘 그 부분 다시 볼까요?',
};
```

## 5. 네비게이션

- 이어서 학습 [이어서 하기] → `nav.push(cont.route, { level: cont.level })` (= readingSession N3)
- 코스 전환 pill / (위젯 탭) → `nav.push('courses')` 또는 `jlptHub`
- MY → `nav.push('my')`

## 6. 구현 방식

- `HomeScreen.jsx` 재작성. `ScrollView`로 세로 스크롤.
- 위젯은 한 파일 내 작은 함수 컴포넌트로 분리(`StatCard`, `ContinueCard`, `ProgressBar`, `AdviceCard`) — 재사용은 파일 내 한정.
- 색/타이포는 테마 토큰(`t.brand`, `t.jlpt`=courseJlpt, `radius` 등) 사용. 카드 그림자 `t.sh1`, 다크는 border(기존 패턴).
- 토모: 인사=`pose="shine"`, 조언=`pose="intellectual"`. 밝기 헤일로 축하 없음(14.2.1).

## 7. 안 건드리는 것

- Tomo 컴포넌트(이미 pose 지원). 다른 화면.
- 하단 5탭 바(이 조각엔 없음, 기존대로).
