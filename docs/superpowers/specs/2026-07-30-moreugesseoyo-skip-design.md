# 「모르겠어요」 스킵 — 설계 (독해·청해 객관식)

- 날짜: 2026-07-30
- 대상 화면: `개발/프론트엔드_무스부/tomori-app/src/screens/QuizScreen.jsx` (독해·청해 공용)
- 백로그 출처: `기획/진행상태.md` — "🅿️ 후속 검토: 「모르겠어요」 스킵(오답처럼 위로+해설)"

## 1. 목적 / 문제

현재 QuizScreen은 **선택지를 골라야만** 「제출하기」가 활성화된다. 확신이 없거나
아예 모르는 학습자에게 **정직하게 넘어갈 도피구가 없다.** 억지로 찍게 만들면
자가판정 데이터도 오염되고, 「학습 의지를 꺾지 않는다」는 토모 철학과도 어긋난다.

단어·문법 카드에는 이미 「알고있음 / 모르겠어요」 자가판정이 있다(WordCardScreen·GrammarCardScreen).
객관식 문제에도 같은 결의 「모르겠어요」 도피구를 준다.

## 2. 결정 사항 (대표님 결정 2026-07-30, 전부 추천대로)

| # | 결정 | 이유 |
|---|---|---|
| D1 | 「모르겠어요」는 **선택지 아래 별도 고스트 버튼**, 항상 활성 | 선택 여부와 무관한 '도피구'. 제출하기와 시각적으로 구분돼 실수로 눌리지 않는다. 상태색 아닌 중립 톤 = 단어카드 자가판정과 결 통일 |
| D2 | 채점은 **오답과 함께 '못 맞춤'** (정답 수 미포함) | 세션 요약(DoneView)은 정답 개수만 보여주면 되고, 별도 집계용 화면 개편이 불필요. 모르겠어요 = 오답과 같이 '복습 대상' |
| D3 | 토모 반응은 **솔직함을 격려하는 전용 문구** | 틀린 게 아니라 모른다고 인정한 것 → 오답 위로("괜찮아요")와 다른 격려 결. 토모 철학(꺾지 않고 북돋움)에 맞음 |

## 3. 동작 흐름

기존 3단(풀이 → 토모 모달 → 결과)에 합류한다.

1. **풀이**: 선택지 아래 「제출하기」(선택 전 disabled). 그 **아래에 「모르겠어요」 고스트 버튼**(항상 활성).
2. 「모르겠어요」 누름 → `correct` 미증가, `selected`는 null 유지 → **토모 반응 모달(unknown)**:
   격려 문구 + 「해설 보기」 버튼 1개(정답 흐름의 2버튼 아님 — 못 맞춘 것이므로).
3. **결과**: 아무것도 안 골랐으므로 오답 마크 없이 **정답만 하이라이트** + 해설.
   후리가나·해석 토글·이 글의 단어는 기존과 동일하게 열린다.

독해·청해 공용 화면이라 **청해에도 자동 적용**(음성만 듣고 「모르겠어요」 가능).

## 4. 구현 (QuizScreen.jsx 한 파일)

- `reaction` 상태 값에 `'unknown'` 추가 (기존 `null | 'correct' | 'wrong'`).
- `skip()` 함수 신설: `if (!q) return; setReaction('unknown');` — `correct` 미증가, `selected` 유지(null).
- 풀이 phase의 제출 버튼 블록(현재 216–224행) 아래에 **「모르겠어요」 고스트 버튼** 추가.
  - 스타일: 신규 `btnGhost`(중립 border, 채움 없음). 상태색(error) 금지.
  - `onPress={skip}`, 항상 활성, `accessibilityLabel="모르겠어요, 해설 보기"`.
- `TomoReaction` 컴포넌트에 `unknown` 분기:
  - 제목 **"솔직하게 말해줘서 좋아요"**, 색 = 중립(`t.textHigh`, error 아님).
  - 부제 **"모르는 걸 아는 것도 실력이에요. 같이 볼까요?"**.
  - 버튼: 「해설 보기」 1개(오답과 동일하게 `onReview` → 결과).
  - 구현상 `kind !== 'correct'`(오답·모름)이면 단일 「해설 보기」 버튼 → 제목/부제만 kind로 분기.

## 5. 안 건드리는 것 (YAGNI)

- **DoneView / 세션 요약**: 채점을 오답과 동일 취급(D2)하므로 변경 불필요.
- **BE / DB / content_vocab_links / TTS**: 무관.
- **밝기(헤일로) 축하 연출**: 「새 쪽지」 전용(PRD 14.2.1) — 여기선 문구·색으로만. 기존 규칙 유지.
- 별도 '모르겠어요' 집계·통계 화면: 이번 범위 밖(추후 학습 데이터 단계에서).

## 6. 검증 방법

FE 빌드(`npm run build`) → `.claude/launch.json` fe(포트 5599) 프리뷰:
- 독해: 풀이 화면에 「모르겠어요」 노출·선택 없이 눌림 → 토모 전용 격려 문구 → 「해설 보기」 →
  결과에 오답 마크 없이 정답만 하이라이트·해설 표시.
- 청해: 음성만 듣고 「모르겠어요」 동일 동작.
- 정답/오답 기존 흐름 회귀 없음(제출하기·2버튼 모달 정상).
- 콘솔 에러 0.

구현·검증 후 `기획/진행상태.md`에 결정·근거 기록(프로젝트 관행).
