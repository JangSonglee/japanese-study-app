# 비즈니스 일본어 코스 — 자료 수집

> 담당: 슈슈(収集) · 단계: 재료 수집 · 최종 갱신: 2026-07-19

## 개요 (수집 범위·기준)
- **대상**: 현지 실사용 비즈니스 표현 출처 — 경어(敬語: 尊敬語/謙譲語/丁寧語) / 이메일·보고서 패턴 / 회의·전화·접대.
- **난이도 기준**: 비즈니스는 JLPT 등급과 별개(PRD 6장) → **입문/초급/중급/고급**으로 표기. 경어 체계 자체가 중급 이상 전제. 정형 인사(입문)→클리셔(초급)→상황 응용(중급)→상황별 접대·교섭(고급).
- **설문 근거**: JLPT와 공동 1위 관심 코스(각 30%, PRD 3장) + 자유응답 "현지에서 쓰는 실용 고급 일본어 필요" → **우선 완성 코스**(PRD 13장).
- **⚠️ 핵심 스타일 지침(README·지시 준수)**: 비즈니스 표현은 **"현지 실제 사용 여부"가 검증되지 않으면 확정 금지**. 아래 출처는 대부분 일본 현지 매체·기업 사이트이나, 개별 표현의 실사용/세대·업계 적합성은 **원어민·현직자 검증 전까지 `⚠️ 검증필요`**로 둔다.

## 난이도 매핑(제안)
| 난이도 | 내용 | 대표 소재 |
|---|---|---|
| 입문 | 기본 정중어(です·ます), 정형 인사 | お世話になっております / よろしくお願いします |
| 초급 | 메일 서두·맺음, 전화 받기 정형 | いつもお世話になっております / 少々お待ちください |
| 중급 | 尊敬語/謙譲語 구분, 완충 표현 | 恐れ入りますが / 承知いたしました / 拝見します |
| 고급 | 상담·교섭·접대, 미묘한 배려 표현 | 검증필요 — 실사용/업계별 편차 큼 |

## 난이도 균형 점검
- 초급~중급(메일·전화·경어 기본)에 자료 풍부. **고급(교섭·접대) 실사용 표현이 상대적으로 얕음** → 국제교류기금 교재 + 현직자 검증으로 보강 필요.
- 입문(정중어 기초)은 JLPT/여행 코스와 일부 중복 → 비즈니스는 경어 이상부터 차별화.

## 추천 우선순위 (PRD 13장: 비즈니스 우선 완성 코스 + 설문 공동1위)
1. **국제교류기금 「いろどり」를 신뢰 축으로** — 라이선스·품질 명확, 무료. 여기서 직장 장면 우선 채택.
2. 메일·전화 정형(초급~중급)부터 콘텐츠화(사용 빈도 최고·검증 용이).
3. 경어 3분류는 중급 핵심 레슨으로.
4. 접대·교섭(고급)은 **현직자 검증 후** 확장 — 미검증 상태로 출시 금지.

## 미해결 / 확인 필요 항목
- ⚠️ **전 영역 `검증필요`**: 민간 사이트 표현(Yagish·마이나비·ロロント·business-mail 등)은 정리 품질은 좋으나 "**현지 실제 사용 빈도·세대/업계 적합성**"은 원어민·현직자 검증 전까지 확정 불가.
- ⚠️ 특히 **접대·교섭 등 고급 표현**은 문서상 표현과 실무 사용이 괴리 클 수 있음 → 최우선 검증 대상.
- ⚠️ 저작권: 민간 사이트 문례 복제 불가. 국제교류기금 교재도 재배포 조건 확인 필요.
- 대표님 확인:
  1. 비즈니스 콘텐츠 **현직자/원어민 감수 채널**을 확보할 수 있는지(검증 병목 해소 핵심).
  2. 경어 난이도를 JLPT 등급과 어떻게 매핑해 보여줄지(현재 입문~고급 독립 체계).
