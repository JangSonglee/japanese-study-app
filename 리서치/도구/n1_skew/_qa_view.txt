=== 품질 샘플 (매 27번째 행) ===
[0001] 即する (そくする) = 입각하다/따르다;부합하다
    예: 現実に即した対策が求められています。
    → 현실에 입각한 대책이 요구되고 있어요.
[0028] 収支 (しゅうし) = 수지/수입과 지출
    예: 今年度の収支は黒字になる見込みです。
    → 올해 수지는 흑자가 될 전망이에요.
[0055] 準ずる (じゅんずる) = 준하다/따르다
    예: 待遇は正社員に準ずる条件で決まりました。
    → 대우는 정규직에 준하는 조건으로 정해졌어요.
[0082] 要する (ようする) = 요하다/필요로 하다
    예: この手術は高度な技術を要します。
    → 이 수술은 고도의 기술을 요해요.
[0109] 確保 (かくほ) = 확보
    예: 災害に備えて飲料水を十分に確保しておく。
    → 재해에 대비해 식수를 충분히 확보해 둬요.
[0136] 振興 (しんこう) = 진흥
    예: 地域の産業を振興するための計画を立てた。
    → 지역 산업을 진흥하기 위한 계획을 세웠어요.
[0163] 感染 (かんせん) = 감염
    예: 手を洗うことで病気の感染を防げる。
    → 손을 씻음으로써 병의 감염을 막을 수 있어요.
[0190] 付け加える (つけくわえる) = 덧붙이다/보태다
    예: 説明の最後に一言だけ付け加えておきたい。
    → 설명 끝에 한마디만 덧붙여 두고 싶어요.
[0217] 武力 (ぶりょく) = 무력/군사력
    예: 対立が深まっても武力による解決は避けるべきだ。
    → 대립이 깊어져도 무력에 의한 해결은 피해야 해요.
[0244] 自立 (じりつ) = 자립/홀로서기
    예: 若者が経済的に自立するには安定した収入が要る。
    → 젊은이가 경제적으로 자립하려면 안정된 수입이 필요해요.
[0271] 広まる (ひろまる) = 널리 퍼지다/확산되다
    예: 根拠のない噂が瞬く間に町中に広まった。
    → 근거 없는 소문이 순식간에 온 마을에 퍼졌어요.
[0298] 適応 (てきおう) = 적응/순응
    예: 新しい環境に適応するには少し時間がかかる。
    → 새로운 환경에 적응하려면 시간이 조금 걸려요.
[0325] 察する (さっする) = 헤아리다/짐작하다
    예: 相手の気持ちを察して言葉を選んだ。
    → 상대의 마음을 헤아려 말을 골랐어요.
[0352] 規範 (きはん) = 규범/본보기
    예: 社会の規範に従って行動する。
    → 사회의 규범에 따라 행동해요.
[0379] 専ら (もっぱら) = 오로지/한결같이
    예: 彼は休日も専ら研究に没頭している。
    → 그는 휴일에도 오로지 연구에 몰두하고 있어요.
