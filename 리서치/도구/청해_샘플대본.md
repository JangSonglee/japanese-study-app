## 0. 왜 이 대본들인가

무작정 아무 문장이나 읽히면 **"셋 다 비슷한데?"** 로 끝난다.
그래서 **TTS가 틀리기 쉬운 것만 골라** 넣었다. 차이가 안 나면 그건 **정말 차이가 없는 것**이고, 차이가 나면 **어디서 나는지 바로 보인다.**

> 사양서 **5.1 「검증 자료의 두 가지 조건」** 을 그대로 적용한다 — 측정이 유효한지부터 확인할 수 있게 설계했다.

**🔴 저작권**: 아래 대본은 **전부 자체 작성**이다. 기출·교재 문항을 복제하지 않았다. JLPT 공식 **유형만** 참고했다.

## 샘플 A — 課題理解형 2인 대화 (청해 문항 본체)

**목적**: 화자 구분 · 자연스러운 주고받기 · 간투사 · 경어
**길이**: 약 180자 (실제 N3 청해 문항과 비슷한 분량)

| 화자 | 대사 |
|---|---|
| 女 | 田中さん、明日の会議の資料、もうできましたか。 |
| 男 | えーと、まだです。今日中に終わらせるつもりですが…。 |
| 女 | そうですか。実は、部長が今日の五時までに見たいとおっしゃっていて。 |
| 男 | えっ、五時ですか。じゃあ、コピーは後にして、先に中身を作ります。 |
| 女 | お願いします。コピーは私がやっておきますね。 |
| 男 | 助かります。ありがとうございます。 |

**質問**: 男の人はこれから何をしますか。

**여기서 확인할 것**
- `えーと` 를 **자연스러운 망설임**으로 읽는가, 아니면 **글자 그대로 "에-토"** 라고 딱딱하게 읽는가 ← 🔴 **가장 티가 나는 지점**
- `えっ` 의 촉음이 **짧게 끊기는가**
- `…` 앞에서 **말끝이 흐려지는가**
- 두 화자 목소리가 **확실히 구분되는가**
- `おっしゃっていて` 같은 **경어가 부자연스럽지 않은가**

## 샘플 B — 단어·예문 (단어 카드용 · 명료도)

**목적**: 촉음·발음(ん)·장음이 정확히 발음되는가
**선정 이유**: 🔴 **슈슈의 한글 발음 파일럿에서 변환기가 처음에 틀렸던 바로 그 단어들**이다. 사람이 듣기에도 어려운 지점이라 TTS도 여기서 갈린다.

| 단어 | 읽기 | 확인 포인트 |
|---|---|---|
| 発表 | はっぴょう | 촉음 `っ` 이 **제대로 멈추는가** |
| 出発 | しゅっぱつ | 촉음 + 요음 |
| 準備 | じゅんび | `ん` 이 **`m` 에 가깝게** 나는가 |
| 天気 | てんき | `ん` 이 **`ng` 에 가깝게** 나는가 |
| 空港 | くうこう | **장음 2개**가 짧아지지 않는가 |
| 場合 | ばあい | 🔴 `ばー` 로 **잘못 이어붙이지 않는가** |

**예문**
- 来週の月曜日に、研究の発表があります。
- 出発の準備はもうできましたか。
- 空港までバスで行く場合、一時間ぐらいかかります。

## 샘플 C — 即時応答형 (짧은 주고받기)

**목적**: 짧은 발화의 **문말 억양** — 질문인지 대답인지가 소리로 구분되는가

| 화자 | 대사 |
|---|---|
| 男 | あのう、すみません。この席、空いていますか。 |
| 女 | あ、はい、どうぞ。 |

| 화자 | 대사 |
|---|---|
| 女 | もう昼ご飯、食べた？ |
| 男 | ううん、まだ。 |

**여기서 확인할 것**
- `〜ますか` 의 **끝이 올라가는가**
- `ううん`(부정) 과 `うん`(긍정) 이 **구분되게 들리는가** ← 초급자에게 실제로 중요한 지점

## 샘플 D — 고저 악센트 (🔴 대조군)

**목적**: **이 샘플이 대조군이다.** 아래 쌍이 **서로 다르게 들리지 않으면**, 그 등급은 일본어 학습용으로 쓸 수 없다.

| 표기 | 읽기 | 뜻 | 악센트 |
|---|---|---|---|
| 橋 / 箸 | はし | 다리 / 젓가락 | 平板 / 頭高 |
| 雨 / 飴 | あめ | 비 / 사탕 | 頭高 / 平板 |
| 今 / 居間 | いま | 지금 / 거실 | 頭高 / 平板 |

**문장으로 확인**
- 箸で食べます。／ 橋を渡ります。
- 雨が降っています。／ 飴を買いました。

> ⚠️ **이게 대조군인 이유**: 일본어는 **고저 악센트가 뜻을 바꾼다.** 셋 다 같게 들린다면 측정이 잘못된 게 아니라 **그 TTS가 악센트를 안 만드는 것**이고, 그러면 **틀린 발음을 가르치게 된다.**
> 폰트 검증에서 *"대조군이 달라야 측정이 유효하다"* 는 규칙을 세운 것과 같은 원리다(사양서 5.1).

## 🎧 청취 체크리스트 (등급별로 ○/△/✕ 기록)

들으면서 이 표를 채운다. **"좋다/나쁘다" 대신 항목별로** 적어야 나중에 근거가 남는다.

| # | 확인 항목 | 샘플 | WaveNet | Neural2 | Chirp3 HD |
|---|---|---|---|---|---|
| 1 | 🔴 **고저 악센트가 쌍마다 다른가** | D | | | |
| 2 | 촉음 `っ` 이 제대로 멈추는가 | B | | | |
| 3 | `ん` 이 뒤 글자에 따라 달라지는가 | B | | | |
| 4 | 장음이 짧아지지 않는가 | B | | | |
| 5 | `ばあい` 를 `ばー` 로 뭉개지 않는가 | B | | | |
| 6 | `えーと` 가 자연스러운 망설임인가 | A | | | |
| 7 | 두 화자가 확실히 구분되는가 | A · C | | | |
| 8 | 문말 억양(질문↑)이 살아 있는가 | C | | | |
| 9 | `うん` / `ううん` 이 구분되는가 | C | | | |
| 10 | 속도가 JLPT 청해와 비슷한가 | A | | | |
| 11 | 오래 들어도 피로하지 않은가 | A | | | |

**판정 기준**
- **1번이 ✕면 그 등급은 탈락**이다. 다른 게 아무리 좋아도 **틀린 발음을 가르치게 된다.**
- 2~5번은 **단어 카드**에 직결 → 여기가 좋으면 단어용으로 채택 가능
- 6~11번은 **청해 문항**에 직결 → 여기가 좋아야 청해용
