## 0.1 ✅ 실제로 들어보고 확정 (2026-07-23)

카드 등록 없이 쓸 수 있는 **Azure Neural 계열 음성**으로 샘플 4종을 만들어 대표님이 직접 청취했다.

| 확인 항목 | 결과 | 판정 |
|---|---|---|
| 🔴 **고저 악센트**(箸/橋 · 雨/飴) — **대조군** | **다르게 들림** | ✅ **관문 통과.** 여기서 막혔으면 등급 자체가 탈락이었다 |
| **단어 정확도**(촉음 · `ん` · 장음 · `ばあい`) | **정확함** | ✅ **단어·예문·받아쓰기는 TTS로 충분** |
| **간투사 `えーと`** | 망설임 없이 **「에-토」로 읽음** | ⚠️ → **아래에서 해결됨** |

### 간투사 문제는 대본 표기로 풀렸다

*"망설임의 본질은 소리가 아니라 침묵"* 이라는 가설로 5개 변형을 만들어 비교 청취했다.

| 변형 | 결과 |
|---|---|
| `えーと、まだです。`(원본) | 어색 |
| **`えーと……。まだです。`** | ✅ **채택 — 자연스러움** |
| `……まだです。`(간투사 제거) | 자연스럽지만 뉘앙스 상실 |
| 속도 −18% / 여운+느리게 | 개선 폭 작음 |

→ **대본 표기 규칙 한 줄로 해결.** `콘텐츠_입력규격.md` **4.4.1** 에 명문화했다.

### 🔴 그래서 확정

| 항목 | 확정 |
|---|---|
| **MVP 음성** | **전량 TTS. 성우 녹음 없음** |
| 근거 | 악센트·단어 정확도 통과 + 간투사는 표기로 해결 |
| 남은 선택 | **Azure로 바로 가도 됨**(방금 들은 것이 그 계열) / 상위 등급이 궁금하면 결제 등록 후 Google 3종 비교 |
| 재확인 조건 | ⚠️ **엔진을 바꾸면 4.4.1 규칙을 다시 들어보고 확정**할 것 |

> **결제 등록보다 청취를 먼저 한 것이 맞았다.** 카드를 먼저 만들었다면 *"등록해놨는데 안 쓰네"* 가 될 뻔했다.

## 0. 결론 먼저

**전량 TTS로 시작하되, 용도에 따라 등급을 나눈다.** 성우 녹음은 MVP에 넣지 않는다.

조사 전 가정은 *"돈이 문제일 것"* 이었는데, **틀렸다.**
우리 콘텐츠 규모에서는 **TTS 비용이 사실상 0**이고, 실제 변수는 **품질 등급**과 **다화자 대화를 만들 수 있는가**였다.

## 1. 🔴 가장 중요한 발견 — 비용은 논점이 아니다

### 우리가 만들어야 하는 분량 (추정)

| 항목 | 계산 | 문자 수 |
|---|---|---|
| JLPT N3 단어 | 2,250개 × (표제어+예문 ≈28자) | 63,000 |
| JLPT N3 문법 | 문형 150개 × 예문 2개 ≈50자 | 7,500 |
| JLPT N3 청해 | 문항 120개 × 대화 ≈250자 | 30,000 |
| 여행 회화 | 8카테고리 × 30표현 × 30자 | 7,200 |
| 비즈니스 | 4영역 × 4난이도 × 25표현 × 35자 | 14,000 |
| **MVP 3코스 합계** | | **≈ 122,000자** |
| 5급수 전체로 확장해도 | | **50만자 미만** |

> ⚠️ 추정치다. 단어 수 분모가 미확정이라(`콘텐츠_입력규격.md` 7장) 자릿수 감만 본다.

### 이 분량의 비용

| 서비스 | 단가 (100만자) | 무료 한도 | **우리 MVP 비용** |
|---|---|---|---|
| **Google WaveNet** | **$4** | **월 400만자** | **$0** (무료 한도 내) |
| Google Neural2 | $16 | 월 100만자 | **$0** |
| Google Chirp 3 HD | $30 | 월 100만자 | **$0** |
| Azure Neural | $15~24 | 월 상당량 | $0~ |
| Amazon Polly | $4 | — | ≈$0.5 |
| ElevenLabs | $165~220 | 구독형 | ≈$25 |

**→ 12만자는 어느 서비스의 무료 한도로도 덮인다.** 신규 Google 계정의 $300 크레딧만으로도 WaveNet 7,500만자를 쓸 수 있다.

> 🔴 **그러므로 "돈을 아끼려고 TTS를 쓴다"는 프레임이 틀렸다.**
> 성우를 쓰지 않는 이유는 비용이 아니라 **수정 가능성**이다 — 콘텐츠가 계속 바뀌는 초기에 녹음본은 **한 글자 고치려면 스튜디오를 다시 잡아야** 한다.

## 2. 연구 근거 — TTS가 학습에 쓸 만한가

**결론: 과제 유형에 따라 다르다.**

| 발견 | 함의 |
|---|---|
| 텍스트 이해·**받아쓰기**·**청취 식별** 과제에서 TTS와 사람 목소리의 성적이 **비슷했다** | 단어·예문·받아쓰기 퀴즈는 **TTS로 충분** |
| **자연스러움 평가는 TTS가 불리**했다 | 긴 대화·정서적 콘텐츠에서는 티가 난다 |
| **고품질 TTS가 저품질보다 정확도 높고 반응시간 짧았다** | 🔴 **"TTS냐 성우냐"가 아니라 "어느 등급의 TTS냐"가 진짜 변수** |
| TTS는 사람 목소리보다 **반응 지연이 길다** = 인지 부하가 크다 | 시험 대비 청해에서 불리하게 작용할 수 있음 |

> **가장 실용적인 시사점**: 저품질 TTS를 쓰면 **학습 성적 자체가 떨어진다.** 무료라고 아무거나 쓰면 안 된다.

## 3. 용도별 권고 — 등급을 나눈다

| 용도 | 성격 | 권고 | 근거 |
|---|---|---|---|
| **단어·예문** | 단일 화자, **명료함**이 목적 | **WaveNet** ($4/1M) | 연구상 식별 과제는 사람과 동등. 분량이 가장 크므로 저가 등급 |
| **표현 카드**(여행·비즈니스) | 단일 화자 + **정중도** 차이 | **Neural2 / Azure**(스타일 지원) | 정중도가 내용의 핵심이라 톤 제어가 필요 |
| 🔴 **JLPT 청해 문항** | **다화자 대화**, 자연 속도 | **Chirp 3 HD / Azure 고급** | 연구가 "고품질이 유의미하게 낫다"고 말하는 지점. **여기에만 돈을 쓴다** |
| **토모의 쪽지** | 정서적 | TTS 미적용(보기 전용) | PRD 14.5 — 보기 전용이라 음성 불필요 |

### 다화자 대화는 TTS로 만들 수 있다

JLPT 청해는 **두 사람 이상의 대화**다. 이게 TTS의 걸림돌처럼 보이지만 실제로는 문제가 아니다.
- Google·Azure 모두 **일본어 화자 20종 이상** 제공 → 화자별로 다른 voice를 지정
- 대사를 **화자 단위로 나눠 생성하고 이어붙인다**
- → 이래서 슈슈 규격에서 **`listening_items` 대본을 발화 단위 자식 테이블로 분리**하자고 한 것이 맞다(스키마 변경 요청 🟠). **음성 제작 파이프라인이 그 구조를 요구한다.**

⚠️ **TTS가 못 만드는 것**: 자연 발화의 **간투사(`えーと`)·말 끊김·겹침**. 실제 시험 음성에는 있다.
→ 우리는 **공식 문항을 복제하지 않고 유형만 차용**하므로 **대본을 우리가 쓴다.** 간투사를 대본에 **명시적으로 넣으면** TTS도 읽는다. 완벽하진 않지만 격차는 줄일 수 있다.

## 4. 🔴 VOICEVOX는 권하지 않는다

무료·일본어 특화·화자 40종 이상이라 후보였지만, **상업 학습 앱에는 맞지 않는다.**

| 문제 | 내용 |
|---|---|
| **크레딧 표기 의무** | 상업 이용 시 **캐릭터별 크레딧 표기 필수**(예: `VOICEVOX: ○○`). 학습 앱 화면 안에 넣어야 한다 |
| **캐릭터마다 약관이 다르다** | 소프트웨어 약관과 **별개로** 캐릭터별 이용 조건이 존재. 40종을 각각 확인해야 하는 법무 부담 |
| 🔴 **음색이 안 맞는다** | 애니메이션 캐릭터 음성이다. **JLPT 청해의 중립적인 사무·안내 톤**과 결이 다르다 |

> 참고: 캐릭터 색이 옅은 **VOICEVOX Nemo** 계열은 상업 이용에 상대적으로 적합하다는 평이 있어, **여행 회화의 가벼운 표현**에 한정해 재검토할 여지는 있다.

**ElevenLabs도 제외**: 일본어 품질이 영어보다 낮다는 평가가 반복되고, 단가가 **40~55배**($165~220/1M)다.

---

## 5. 🔴 지금 결정에서 가장 중요한 것 — 나중에 바꿀 수 있게 둔다

성우 녹음을 **영구히 배제하는 것이 아니다.** 출시 후 반응을 보고 청해만 성우로 교체할 수 있다.

그러려면 **지금 구조를 이렇게 잡아야 한다.**

| # | 조건 | 이유 |
|---|---|---|
| 1 | **음성은 파일 참조로만 저장** (`audio_file` 경로) | 이미 슈슈 규격에 있음. 파일만 갈아끼우면 교체 완료 |
| 2 | **대본을 원본으로 보관** (`listening_items` 발화 단위) | 대본이 있어야 재생성·재녹음이 가능. **음성 파일만 있으면 못 고친다** |
| 3 | **생성 파라미터를 기록** (`voice_preset`·`speed`) | 슈슈가 요청한 컬럼. 없으면 **일관된 재생성이 불가능**하다 |
| 4 | **파일명 규칙 고정** (`content_key` 기반) | 이미 확정. 재생성해도 경로가 안 바뀐다 |

> ⭐ 3·4가 없으면 "1년 뒤 단어 200개를 고쳤는데 그 200개만 다시 만들 수가 없는" 상황이 된다.

## 6. 권고안 요약

| 항목 | 권고 |
|---|---|
| **MVP** | **전량 TTS.** 성우 녹음 없음 |
| 단어·예문 | Google **WaveNet** (저가·대량) |
| 표현 카드 | **Neural2** 또는 Azure(스타일 제어) |
| **JLPT 청해** | **Chirp 3 HD / Azure 고급** — 여기에만 상위 등급 |
| 예상 비용 | **거의 0** (무료 한도 내, 초과해도 연 몇 달러) |
| VOICEVOX | ❌ 크레딧 의무 + 캐릭터 약관 + 음색 부적합 |
| 출시 후 | 청해만 성우 교체 검토 — **5장 4조건을 지키면 언제든 가능** |

**선행 조건 1건**: 후보 3종(WaveNet / Neural2 / Chirp 3 HD)으로 **같은 청해 대본을 실제로 생성해 비교 청취**할 것. 사양서 5.1의 *"검증 자료의 두 조건"* 을 여기에도 적용한다 — **귀로 확인하지 않고 등급을 정하지 않는다.**
