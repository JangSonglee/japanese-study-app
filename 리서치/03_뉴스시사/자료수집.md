# 뉴스·시사 코스 — 자료 수집

> 담당: 슈슈(収集) · 단계: 재료 수집 · 최종 갱신: 2026-07-19

## 개요 (수집 범위·기준)
- **대상**: 난이도별 뉴스 기사 출처 — PRD 4장/6장 방침 "**NHK Web Easy 수준 → 원문 순서**"에 맞춰 易化 뉴스(N5~N3) → 원문 뉴스(N2~N1)로 축을 구성.
- **난이도 기준**:
  - N5~N4: やさしい日本語 뉴스(후리가나·어휘 주석·낭독 포함)
  - N3: NHK NEWS WEB EASY 표준(후리가나 있으나 어휘 난도 중급)
  - N2~N1: 일반 뉴스 원문(후리가나 없음, 시사 한자·표현)
- **저작권 주의**: 뉴스 기사 원문은 **각 언론사 저작물** → 앱 내 전문 복제·상시 게재 불가. 아래는 출처 목록이며, 실제 콘텐츠는 요약·발췌·리라이트 또는 **정식 제휴/라이선스** 필요(별도 검수).

## "쉬운 버전 ↔ 원문" 페어링 전략 (PRD 핵심 동선)
NHK가 **동일 사건을 EASY(易化)와 일반 기사 양쪽으로 제공**하는 점을 활용:
1. 같은 뉴스의 EASY판(N4~N3) → 일반판(N2~N1)을 한 세트로 묶어 "난이도 상승 독해" 레슨 구성.
2. 후리가나 토글(PRD 8.4)과 결합해 동일 기사 내에서도 난이도 조절.
3. → 별도 소재 확보 없이 한 사건으로 다등급 레슨 생산 가능(콘텐츠 제작비 절감).

## 난이도 균형 점검
- N5 순수(완전 입문) 뉴스는 원천이 드묾 → やさしい日本語 뉴스도 실제 N4~N3 체감. **N5 갭 존재**, 자체 초易化 또는 뉴스 대신 짧은 공지문/생활정보로 보완 검토.
- N3~N1은 NHK 축으로 충분히 균형 확보.

## 추천 우선순위 (PRD 13장: 뉴스·시사는 후순위 코스, 그러나 차별화 소재)
1. **NHK NEWS WEB EASY를 축으로** MVP 구성(후리가나·음성·사전팝업이 PRD 기능과 정합).
2. EASY↔원문 페어링으로 N4→N2 상승 레슨 우선 제작.
3. N1 시사 원문은 상급 확장 단계로.

## 미해결 / 확인 필요 항목
- ⚠️ **저작권 핵심 리스크**: NHK/신문 기사 전문 복제·상시 게재 불가. 앱 내 사용 방식(요약·발췌·링크·정식 제휴 중 무엇) **대표님·법무 결정 필수**.
- ⚠️ NHK NEWS WEB EASY 도메인 이전(www3.nhk.or.jp → news.web.nhk) 확인 중 → 실제 서비스 URL 최종 확정 필요.
- ⚠️ NHK 콘텐츠의 학습앱 상업 이용 가부(API·제휴 창구 존재 여부) 확인 필요.
- N5 완전 입문급 뉴스 소재 공백 → 보완안(생활 공지문/기상·교통 안내 등) 검토 필요.
